## 🗣️ 提问技巧

### 好问题的标准

**一个好的问题应该包含：**
1. **明确的任务** - 你想让 AI 做什么
2. **足够的背景** - 相关的上下文信息
3. **具体的格式** - 你期望的输出形式
4. **参考示例** - 如果有的话

---

### 提问公式

**万能公式：**
```
角色 + 任务 + 背景 + 格式 + 示例
```

**示例对比：**

❌ **不好的提问：**
```
写一篇文章
```

✅ **好的提问：**
```
你是一位资深新媒体运营专家。

请帮我写一篇关于"职场时间管理"的公众号文章。

背景：
- 目标读者是25-35岁的上班族
- 他们工作忙碌，时间碎片化
- 需要实用的方法，不要太多理论

要求：
- 800-1000字
- 风格轻松幽默
- 包含3-5个具体方法
- 结尾要有行动建议

参考风格：
类似"Ali Abdaal"的效率视频风格，有干货但不枯燥
```

---

### 常用提问模板

#### 写作模板
```
请帮我写一篇[类型]文章

主题：[主题]
目标读者：[读者画像]
字数：[字数]
风格：[风格要求]
必须包含：[要点]
避免：[不要的内容]
```

#### 编程模板
```
请帮我用[语言]实现[功能]

背景：[项目背景]
输入：[输入说明]
输出：[输出说明]
约束：[限制条件]
```

#### 分析模板
```
请帮我分析[主题]

数据/内容：[具体内容]
分析维度：[分析角度]
输出格式：[期望格式]
关注重点：[重点关注]
```

## 🔄 对话技巧

### 分步骤提问

**为什么分步骤？**
- AI 一次处理复杂任务容易出错
- 分步骤可以逐步优化
- 更容易控制质量

**示例：**

❌ **一次问完：**
```
帮我做一个完整的市场分析报告，包括市场规模、竞争格局、用户画像、发展趋势，要详细。
```

✅ **分步骤：**
```
第一步：
先帮我列出市场分析报告的大纲

第二步：
根据大纲，先完成"市场规模"部分的分析

第三步：
继续完成"竞争格局"部分

...
```

---

### 迭代优化

**不要期望一次就完美：**
- 第一版可能只有 60 分
- 通过迭代提升到 80 分
- 最终达到 95 分

**迭代示例：**
```
第一轮：
用户：帮我写一个产品介绍
AI：[输出内容]

第二轮：
用户：太长了，帮我精简到200字以内
AI：[精简内容]

第三轮：
用户：加入一些数据支撑
AI：[添加数据]

第四轮：
用户：结尾加一个行动号召
AI：[最终版本]
```

---

### 给 AI 反馈

**如何给 AI 有效反馈：**

✅ **具体的反馈：**
```
"这个太正式了，帮我改成口语化的风格"
"第三段的例子不合适，换成和年轻人相关的"
"开头太长了，缩短到50字以内"
```

❌ **模糊的反馈：**
```
"再好一点"
"改改"
"不行"
```

## 📝 内容创作技巧

### 写作场景

#### 快速生成大纲
```
请帮我为"[主题]"写一个文章大纲

要求：
- 3-5个主要部分
- 每个部分2-3个要点
- 逻辑清晰，层层递进
```

#### 风格模仿
```
请模仿以下风格写一篇文章：

[粘贴一段参考文本]

主题：[你的主题]
```

#### 内容扩写
```
请帮我扩写以下内容，增加细节和例子：

[原始内容]

要求：
- 增加具体案例
- 添加数据支撑
- 丰富细节描写
```

---

### 编程场景

#### 从零开始
```
请帮我创建一个[项目类型]

功能需求：
1. [需求1]
2. [需求2]
3. [需求3]

技术栈：[技术选择]
```

#### 代码优化
```
请帮我优化以下代码：

[粘贴代码]

优化目标：
- 提升性能
- 增强可读性
- 添加注释
```

#### Bug 修复
```
这段代码有问题，请帮我找出并修复：

[粘贴代码]

错误信息：[错误信息]
预期行为：[正确的行为]
```

## 🎯 高效使用技巧

### 使用快捷键

**常用快捷键：**
- `Enter`：发送消息
- `Shift + Enter`：换行
- `Ctrl + N`：新对话（部分工具）
- `Ctrl + Shift + C`：复制代码块

---

### 管理对话历史

**为什么重要？**
- 保持上下文连贯
- 避免重复解释
- 提高回答质量

**最佳实践：**
- 一个任务一个对话
- 及时总结重要信息
- 定期清理无用对话

---

### 利用 AI 的记忆

**让 AI 记住重要信息：**
```
请记住以下信息，后续对话中会用到：

我的背景：[你的背景]
我的偏好：[你的偏好]
项目信息：[项目信息]
```

## 🔧 高级技巧

### 让 AI 扮演角色

**角色提示词：**
```
你是一位资深[角色]，拥有[经验/技能]。

你的回答应该：
- [特点1]
- [特点2]
- [特点3]
```

**常用角色：**
- 资深程序员
- 产品经理
- 文案专家
- 数据分析师
- 英语老师

---

### Chain of Thought（思维链）

**让 AI 展示思考过程：**
```
请一步步思考这个问题：

1. 先分析问题
2. 列出可能的方案
3. 评估每个方案
4. 给出最终答案

问题：[你的问题]
```

---

### 让 AI 自我检查

**在回答后让 AI 检查：**
```
请回答以下问题，然后检查你的答案是否正确：

问题：[问题]

回答后，请：
1. 检查是否有遗漏
2. 验证逻辑是否正确
3. 确认是否回答了所有问题
```

## ⚠️ 避坑指南

### 常见错误

#### 1. 问题太模糊
```
❌ 帮我写点东西
✅ 帮我写一篇500字的产品介绍
```

#### 2. 期望一次完美
```
❌ 一次就要完美
✅ 先生成初稿，再迭代优化
```

#### 3. 不给背景信息
```
❌ 怎么学编程？
✅ 我是产品经理，想学Python做数据分析，每天1小时
```

#### 4. 盲目相信 AI
```
❌ AI说的都是对的
✅ 重要信息需要验证
```

---

### 最佳实践

1. **每次只做一件事**
   - 不要一次让 AI 做太多
   - 分步骤完成

2. **提供足够的上下文**
   - AI 不是你肚子里的蛔虫
   - 背景信息越多越好

3. **及时反馈**
   - 不满意就说出来
   - 具体指出问题在哪

4. **保存好的 Prompt**
   - 好的提示词值得保存
   - 可以重复使用
