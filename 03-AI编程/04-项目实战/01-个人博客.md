# 实战：个人博客网站

> 从零开始，用 AI 创建你的第一个网站

---

## 📋 项目概述

**项目目标：** 创建一个简洁美观的个人博客网站

**技术栈：**
- HTML（网页结构）
- CSS（样式设计）
- JavaScript（可选，交互功能）

**难度：** ⭐ 入门级

**预计时间：** 1-2 小时

---

## 🎯 最终效果

完成后你将拥有：
- ✅ 一个可以访问的博客网站
- ✅ 包含首页、文章列表、关于页面
- ✅ 响应式设计，支持手机访问
- ✅ 现代美观的界面

---

## 🛠️ 准备工作

### 需要安装

1. **Cursor 编辑器**
   - 下载：[cursor.sh](https://cursor.sh)
   - 安装后打开，登录账号

2. **浏览器**
   - Chrome 或 Edge（用于预览）

---

## 🚀 开始开发

### 第 1 步：创建项目文件夹

**在终端执行：**
```bash
# 创建项目目录
mkdir my-blog

# 进入目录
cd my-blog

# 用 Cursor 打开
cursor .
```

---

### 第 2 步：让 AI 创建基础结构

**在 Cursor 中按 Cmd+I（Mac）或 Ctrl+I（Windows），输入：**

```
帮我创建一个个人博客网站的基础结构，包含：
1. index.html - 首页
2. about.html - 关于页面
3. style.css - 样式文件

要求：
- 现代、简洁的设计风格
- 深色主题
- 响应式设计
```

**AI 会生成三个文件的基本内容。**

---

### 第 3 步：完善首页

**继续输入：**

```
请完善 index.html 首页，包含：
1. 导航栏（首页、文章、关于）
2. 英雄区域（大标题、个人简介）
3. 最新文章列表（3-5 篇文章卡片）
4. 页脚（版权信息、社交媒体链接）

样式要现代美观，使用渐变背景
```

---

### 第 4 步：完善样式

**输入：**

```
请完善 style.css，要求：
1. 深色主题（深灰色背景、白色文字）
2. 渐变色调（紫色到蓝色的渐变作为强调色）
3. 卡片式文章列表
4. 平滑的悬停动画效果
5. 响应式设计（支持手机、平板、桌面）
6. 导航栏固定在顶部
```

---

### 第 5 步：创建关于页面

**输入：**

```
请创建 about.html 关于页面，包含：
1. 个人头像区域
2. 自我介绍
3. 技能标签
4. 联系方式
5. 社交媒体链接

保持与首页一致的设计风格
```

---

### 第 6 步：预览网站

**方法一：直接打开**
```bash
# 在项目目录下
open index.html
```

**方法二：使用 VS Code Live Server**
- 安装 Live Server 扩展
- 右键点击 index.html
- 选择 "Open with Live Server"

## 💡 常见调整

### 修改颜色

**告诉 AI：**
```
请把主题色从紫色改为绿色，保持深色背景
```

---

### 添加更多文章

**告诉 AI：**
```
请在首页添加更多文章卡片，总共显示 6 篇文章
```

---

### 修改个人简介

**直接编辑 index.html 中的文字即可，或告诉 AI：**
```
请把首页的简介改为：
"你好，我是 [你的名字]，一名热爱技术的开发者..."
```

---

### 添加暗色/亮色切换

**告诉 AI：**
```
请添加一个深色/浅色主题切换按钮，
点击可以切换网站的配色方案
```

## 🚀 部署上线

### 方法一：GitHub Pages（免费）

1. **创建 GitHub 仓库**
   ```bash
   git init
   git add .
   git commit -m "Initial commit"
   ```

2. **推送到 GitHub**
   - 在 GitHub 创建新仓库
   - 按提示推送代码

3. **开启 Pages**
   - 进入仓库 Settings
   - 找到 Pages
   - 选择 main 分支
   - 保存后获得网址

### 方法二：Vercel（推荐）

1. 访问 [vercel.com](https://vercel.com)
2. 用 GitHub 登录
3. 导入你的仓库
4. 一键部署

## ❓ 常见问题

<details>
<summary><b>Q: 中文显示乱码怎么办？</b></summary>

**A: 确保文件编码是 UTF-8**

在 HTML 的 `<head>` 中添加：
```html
<meta charset="UTF-8">
```
</details>

<details>
<summary><b>Q: 样式没有生效怎么办？</b></summary>

**A: 检查 CSS 文件链接**

确保 HTML 中正确引入了 CSS：
```html
<link rel="stylesheet" href="style.css">
```
</details>

<details>
<summary><b>Q: 手机上显示不正常怎么办？</b></summary>

**A: 添加视口设置**

在 HTML 的 `<head>` 中添加：
```html
<meta name="viewport" content="width=device-width, initial-scale=1.0">
```
</details>
