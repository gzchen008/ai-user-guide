# 实战：待办事项应用

> 用 AI 开发你的第一个交互式 Web 应用

---

## 📋 项目概述

**项目目标：** 创建一个功能完整的待办事项（Todo List）应用

**你将学到：**
- ✅ JavaScript 基础交互
- ✅ DOM 操作
- ✅ 本地存储（LocalStorage）
- ✅ 事件处理
- ✅ AI 辅助开发流程

**难度：** ⭐⭐（入门级）
**预计时间：** 2-3 小时
**推荐工具：** Cursor

---

## 🎯 功能需求

### 核心功能

1. **添加待办事项**
   - 输入框输入任务
   - 点击按钮或回车添加
   - 新任务显示在列表顶部
   - 输入验证（防止空任务）

2. **标记完成**
   - 点击任务切换完成状态
   - 完成的任务显示删除线
   - 视觉区分已完成和未完成
   - 支持批量标记

3. **删除任务**
   - 每个任务有删除按钮
   - 点击删除按钮移除任务
   - 删除前确认提示（防误删）

4. **本地存储**
   - 刷新页面数据不丢失
   - 自动保存到浏览器
   - 数据导入导出功能

### 实用场景功能

5. **任务分类**
   - 工作任务、个人任务、学习任务
   - 不同颜色标识
   - 分类统计

6. **优先级管理**
   - 高、中、低优先级
   - 优先级图标显示
   - 按优先级排序

7. **时间管理**
   - 任务截止时间设置
   - 倒计时提醒
   - 逾期任务高亮

8. **数据统计**
   - 完成率显示
   - 每日完成趋势
   - 任务数量统计

### 高级功能（可选）

9. **编辑任务**
   - 双击任务可以编辑
   - 支持富文本编辑
   - 编辑历史记录

10. **筛选和搜索**
    - 显示全部/已完成/未完成
    - 按分类筛选
    - 关键词搜索
    - 标签筛选

11. **数据管理**
    - 清空已完成
    - 批量删除
    - 数据备份恢复

### 第 4 步：实现 JavaScript 逻辑

**向 AI 提问：**
```
帮我实现待办事项应用的 JavaScript 功能：
1. 添加任务（点击按钮或回车）
2. 标记完成（点击复选框）
3. 删除任务
4. 本地存储（刷新不丢失）
5. 筛选功能（全部/未完成/已完成）
6. 清空已完成任务
7. 任务统计
```

**示例代码：**

```javascript
// 获取 DOM 元素
const todoInput = document.getElementById('todoInput');
const addBtn = document.getElementById('addBtn');
const todoList = document.getElementById('todoList');
const itemCount = document.getElementById('itemCount');
const clearCompleted = document.getElementById('clearCompleted');
const filterBtns = document.querySelectorAll('.filter-btn');

// 从本地存储加载任务
let todos = JSON.parse(localStorage.getItem('todos')) || [];
let currentFilter = 'all';

// 初始化应用
function init() {
  renderTodos();
  updateCount();
}

// 保存到本地存储
function saveTodos() {
  localStorage.setItem('todos', JSON.stringify(todos));
}

// 添加任务
function addTodo() {
  const text = todoInput.value.trim();
  
  if (text === '') {
    alert('请输入任务内容');
    return;
  }
  
  const todo = {
    id: Date.now(),
    text: text,
    completed: false
  };
  
  todos.unshift(todo); // 添加到开头
  saveTodos();
  renderTodos();
  updateCount();
  
  todoInput.value = ''; // 清空输入框
  todoInput.focus(); // 聚焦输入框
}

// 渲染任务列表
function renderTodos() {
  // 根据筛选条件过滤任务
  let filteredTodos = todos;
  
  if (currentFilter === 'active') {
    filteredTodos = todos.filter(todo => !todo.completed);
  } else if (currentFilter === 'completed') {
    filteredTodos = todos.filter(todo => todo.completed);
  }
  
  // 生成 HTML
  todoList.innerHTML = filteredTodos.map(todo => `
    <li class="todo-item ${todo.completed ? 'completed' : ''}" data-id="${todo.id}">
      <input 
        type="checkbox" 
        class="todo-checkbox" 
        ${todo.completed ? 'checked' : ''}
        onchange="toggleTodo(${todo.id})"
      >
      <span class="todo-text">${todo.text}</span>
      <button class="delete-btn" onclick="deleteTodo(${todo.id})">删除</button>
    </li>
  `).join('');
}

// 切换完成状态
function toggleTodo(id) {
  todos = todos.map(todo => {
    if (todo.id === id) {
      return { ...todo, completed: !todo.completed };
    }
    return todo;
  });
  
  saveTodos();
  renderTodos();
  updateCount();
}

// 删除任务
function deleteTodo(id) {
  todos = todos.filter(todo => todo.id !== id);
  saveTodos();
  renderTodos();
  updateCount();
}

// 清空已完成任务
function clearCompletedTodos() {
  const completedCount = todos.filter(todo => todo.completed).length;
  
  if (completedCount === 0) {
    alert('没有已完成的任务');
    return;
  }
  
  if (confirm(`确定要删除 ${completedCount} 个已完成的任务吗？`)) {
    todos = todos.filter(todo => !todo.completed);
    saveTodos();
    renderTodos();
    updateCount();
  }
}

// 更新任务统计
function updateCount() {
  const activeCount = todos.filter(todo => !todo.completed).length;
  const totalCount = todos.length;
  itemCount.textContent = `${activeCount} 个未完成 / 共 ${totalCount} 个任务`;
}

// 筛选任务
function setFilter(filter) {
  currentFilter = filter;
  
  // 更新按钮状态
  filterBtns.forEach(btn => {
    btn.classList.remove('active');
    if (btn.dataset.filter === filter) {
      btn.classList.add('active');
    }
  });
  
  renderTodos();
}

// 事件监听
addBtn.addEventListener('click', addTodo);

// 回车添加
todoInput.addEventListener('keypress', (e) => {
  if (e.key === 'Enter') {
    addTodo();
  }
});

// 清空已完成
clearCompleted.addEventListener('click', clearCompletedTodos);

// 筛选按钮
filterBtns.forEach(btn => {
  btn.addEventListener('click', () => {
    setFilter(btn.dataset.filter);
  });
});

// 启动应用
init();
```

```javascript
// 编辑任务
function editTodo(id, newText) {
  if (newText.trim() === '') {
    alert('任务内容不能为空');
    renderTodos();
    return;
  }
  
  todos = todos.map(todo => {
    if (todo.id === id) {
      return { ...todo, text: newText.trim() };
    }
    return todo;
  });
  
  saveTodos();
  renderTodos();
}

// 在渲染函数中添加双击事件
todoList.innerHTML = filteredTodos.map(todo => `
  <li class="todo-item ${todo.completed ? 'completed' : ''}" data-id="${todo.id}">
    <input 
      type="checkbox" 
      class="todo-checkbox" 
      ${todo.completed ? 'checked' : ''}
      onchange="toggleTodo(${todo.id})"
    >
    <span 
      class="todo-text" 
      ondblclick="makeEditable(this, ${todo.id})"
    >${todo.text}</span>
    <button class="delete-btn" onclick="deleteTodo(${todo.id})">删除</button>
  </li>
`).join('');

// 使任务可编辑
function makeEditable(element, id) {
  const currentText = element.textContent;
  const input = document.createElement('input');
  input.type = 'text';
  input.value = currentText;
  input.className = 'edit-input';
  
  element.innerHTML = '';
  element.appendChild(input);
  input.focus();
  input.select();
  
  // 保存编辑
  function saveEdit() {
    editTodo(id, input.value);
  }
  
  // 回车保存
  input.addEventListener('keypress', (e) => {
    if (e.key === 'Enter') {
      saveEdit();
    }
  });
  
  // 失去焦点保存
  input.addEventListener('blur', saveEdit);
  
  // ESC 取消
  input.addEventListener('keydown', (e) => {
    if (e.key === 'Escape') {
      renderTodos();
    }
  });
}
```

## ❓ 常见问题

<details>
<summary><b>Q: 本地存储有什么限制？</b></summary>

**A:** LocalStorage 的限制：
- 容量限制：5-10MB
- 只能存储字符串
- 同源策略限制
- 用户可以手动清除

**建议：** 大量数据使用后端数据库
</details>

<details>
<summary><b>Q: 如何让数据在多个设备同步？</b></summary>

**A:** 需要添加后端：
1. 搭建 Node.js 服务器
2. 使用数据库（MongoDB/MySQL）
3. 添加用户登录
4. 实现数据同步 API
</details>

<details>
<summary><b>Q: 代码太多看不懂怎么办？</b></summary>

1. 让 AI 逐行解释代码
2. 先理解整体流程
3. 再深入每个函数
4. 动手修改实验
</details>
