## 💡 AI 编程核心技巧

### 1. 清晰描述需求

```
❌ 不好的描述：
帮我写个网页

✅ 好的描述：
帮我创建一个个人博客网站首页，要求：
- 现代、简洁的设计风格
- 包含导航栏、英雄区、文章列表、页脚
- 响应式设计，支持手机访问
- 使用深色主题
```

---

### 2. 分步骤开发

```
不要一次性让 AI 生成整个项目：

第 1 步：创建项目结构
第 2 步：实现基础页面
第 3 步：添加样式
第 4 步：实现交互功能
第 5 步：测试和优化
```

---

### 3. 主动学习

```
每完成一段代码，问 AI：

- 这段代码的作用是什么？
- 为什么要这样写？
- 有没有更好的方法？
- 如果我想修改某个功能，应该怎么改？
```

---

### 4. 善用注释

```
让 AI 在代码中添加详细注释：

function calculateTotal(items) {
  // 初始化总价为 0
  let total = 0;
  
  // 遍历每个商品
  for (let item of items) {
    // 价格 × 数量 = 小计
    total += item.price * item.quantity;
  }
  
  // 返回总价
  return total;
}
```

## 📝 项目开发流程

### 标准流程

```
1. 需求分析
   - 明确项目目标
   - 列出功能清单
   - 确定技术选型

2. 项目初始化
   - 创建项目目录
   - 初始化项目配置
   - 设置开发环境

3. 核心功能开发
   - 从最核心的功能开始
   - 逐步添加功能
   - 边写边测试

4. 样式美化
   - 添加 CSS 样式
   - 优化用户体验
   - 响应式适配

5. 测试优化
   - 功能测试
   - 修复 bug
   - 性能优化

6. 部署上线
   - 选择部署平台
   - 配置域名
   - 发布项目
```

## ⚠️ 常见问题

### Q1: AI 生成的代码报错怎么办？

**解决步骤：**
1. 把错误信息复制给 AI
2. 让 AI 解释错误原因
3. 让 AI 提供修复方案
4. 按步骤修复

---

### Q2: 不知道下一步该做什么？

**解决方法：**
- 问 AI："接下来应该做什么？"
- 让 AI 列出待完成的功能
- 选择一个功能继续开发

---

### Q3: 代码太多看不懂？

**解决方法：**
- 让 AI 逐行解释代码
- 要求添加详细注释
- 分模块学习，不要一次性理解所有代码

---

### Q4: 项目太复杂怎么办？

**解决方法：**
- 把大项目拆分成小任务
- 一次只做一个功能
- 先完成再完美

---

**💡 小贴士：** 实战是最好的学习方式！选一个感兴趣的项目，跟着教程一步步完成，遇到问题就问 AI，完成后你会发现编程没那么难！
