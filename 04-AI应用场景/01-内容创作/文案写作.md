## 📝 AI 写文案的万能公式

### 公式1：PAS 模型

**PAS = Problem（问题）+ Agitation（痛点）+ Solution（方案）**

**示例：**
```
Problem: 每天手动回复客户咨询，耗时费力
Agitation: 错过订单，客户流失，效率低下
Solution: AI 客服机器人，24小时自动回复
```

---

### 公式2：AIDA 模型

**AIDA = Attention（注意）+ Interest（兴趣）+ Desire（欲望）+ Action（行动）**

**示例：**
```
Attention: 🔥 这个工具让我效率提升10倍！
Interest: 它可以自动写文案、生成图片、剪辑视频
Desire: 想象一下，你的工作效率翻倍，有更多时间享受生活
Action: 点击链接，立即体验 👇
```

---

### 公式3：FAB 模型

**FAB = Feature（特点）+ Advantage（优势）+ Benefit（好处）**

**示例：**
```
Feature: 这款 AI 工具支持 29 种语言
Advantage: 比其他工具支持的语言更多
Benefit: 可以帮你拓展全球市场
```

## 🎯 AI 写文案的最佳实践

### ✅ DO（推荐做法）

1. **提供详细上下文**
   ```
   ❌ 帮我写个文案
   
   ✅ 写一篇小红书笔记，主题是AI工具，目标用户是25-35岁职场女性
   ```

2. **指定语气和风格**
   ```
   语气：亲切、活泼、像朋友聊天
   风格：小红书风格，带emoji
   ```

3. **提供示例**
   ```
   参考这个风格的文案：[粘贴示例]
   ```

4. **多轮迭代**
   ```
   第一轮：生成初稿
   第二轮：调整语气
   第三轮：优化标题
   第四轮：添加emoji
   ```

---

### ❌ DON'T（避免做法）

1. **需求不清晰**
   ```
   ❌ 写个好的文案
   ```

2. **一次性要求太多**
   ```
   ❌ 写10篇不同风格的文案
   ```

3. **不提供目标受众**
   ```
   ❌ 写个广告（没说是给谁看的）
   ```

4. **完全复制粘贴**
   ```
   ❌ AI生成的文案直接发布（没有个性化调整）
   ```

<summary><b>Q: AI 写的文案会被判定为抄袭吗？</b></summary>

**A: 不会，但需要个性化。**

- ✅ AI 生成的内容是原创的
- ⚠️ 但很多人用同样的 Prompt 会生成类似内容
