## 📝 AI 写文案的万能公式

### 公式1：PAS 模型

**PAS = Problem（问题）+ Agitation（痛点）+ Solution（方案）**

**示例：**
```
Problem: 每天手动回复客户咨询，耗时费力
Agitation: 错过订单，客户流失，效率低下
Solution: AI 客服机器人，24小时自动回复
```

---

### 公式2：AIDA 模型

**AIDA = Attention（注意）+ Interest（兴趣）+ Desire（欲望）+ Action（行动）**

**示例：**
```
Attention: 🔥 这个工具让我效率提升10倍！
Interest: 它可以自动写文案、生成图片、剪辑视频
Desire: 想象一下，你的工作效率翻倍，有更多时间享受生活
Action: 点击链接，立即体验 👇
```

---

### 公式3：FAB 模型

**FAB = Feature（特点）+ Advantage（优势）+ Benefit（好处）**

**示例：**
```
Feature: 这款 AI 工具支持 29 种语言
Advantage: 比其他工具支持的语言更多
Benefit: 可以帮你拓展全球市场
```

## 🎯 AI 写文案的最佳实践

### ✅ DO（推荐做法）

1. **提供详细上下文**
   ```
   ❌ 帮我写个文案
   
   ✅ 写一篇小红书笔记，主题是AI工具，目标用户是25-35岁职场女性
   ```

2. **指定语气和风格**
   ```
   语气：亲切、活泼、像朋友聊天
   风格：小红书风格，带emoji
   ```

3. **提供示例**
   ```
   参考这个风格的文案：[粘贴示例]
   ```

4. **多轮迭代**
   ```
   第一轮：生成初稿
   第二轮：调整语气
   第三轮：优化标题
   第四轮：添加emoji
   ```

---

### ❌ DON'T（避免做法）

1. **需求不清晰**
   ```
   ❌ 写个好的文案
   ```

2. **一次性要求太多**
   ```
   ❌ 写10篇不同风格的文案
   ```

3. **不提供目标受众**
   ```
   ❌ 写个广告（没说是给谁看的）
   ```

4. **完全复制粘贴**
   ```
   ❌ AI生成的文案直接发布（没有个性化调整）
   ```

## 🛠️ 高级技巧

### 1. 情绪化文案
```
❌ 客服机器人多少钱？
✅ 还在为客服成本高烦恼吗？看看这款机器人！
```

### 2. 数字化表达
```
❌ 我们的软件很好用
✅ 10万+企业选择，效率提升300%
```

### 3. 场景化描述
```
❌ 这个耳机音质很好
✅ 通勤路上，让音乐带你穿越时空；运动时，激情旋律陪你挥洒汗水
```

### 4. 对比式营销
```
❌ 我们的空调很省电
✅ 一度电用24小时，普通空调一度电用8小时
```

---

**💡 小贴士：** AI 写文案的核心是"好 Prompt + 人工润色"，AI 是助手，你才是导演！记住：

1. **具体化：** 提供越详细的信息，AI生成越好
2. **场景化：** 让AI理解使用场景，写出更有共鸣的内容
3. **个性化：** 生成后加入自己的风格和真实经历
4. **数据化：** 用具体数据增强说服力
5. **迭代化：** 第一次不满意，继续优化Prompt

**🚀 进阶建议：** 建立"文案prompt库"，收集成功的案例和模板，越用越顺手！
