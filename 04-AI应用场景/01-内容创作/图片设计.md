## 💡 AI图片设计技巧

### 技巧1：写好提示词

```
提示词结构：
[主体] + [风格] + [细节] + [参数]

示例：
A cute cat (主体)
in watercolor style (风格)
sitting on a window sill, sunlight streaming in (细节)
--ar 16:9 (参数)

更详细的提示词 = 更好的结果
```

---

### 技巧2：指定风格

```
常用风格关键词：

艺术风格：
- watercolor (水彩)
- oil painting (油画)
- pixel art (像素风)
- minimalist (极简)
- cyberpunk (赛博朋克)

视角：
- close-up (特写)
- wide angle (广角)
- top-down (俯视)
- side view (侧面)

光影：
- golden hour (黄金时段)
- studio lighting (摄影棚光)
- natural light (自然光)
- dramatic lighting (戏剧性光影)
```

---

### 技巧3：控制比例

```
常用比例参数：
--ar 16:9   横屏（封面）
--ar 9:16   竖屏（手机）
--ar 1:1    正方形（头像）
--ar 2:3    海报
--ar 3:4    竖版海报
```

---

### 技巧4：迭代优化

```
第1轮：生成初稿
第2轮：调整风格
第3轮：优化细节
第4轮：生成高清版本
第5轮：后期处理

AI生成+人工优化=最佳效果
```

---

### 技巧5：组合使用

```
工作流：
1. MidJourney生成艺术图
2. Ideogram加文字
3. Photoshop后期调整
4. 导出使用

每个工具发挥所长
```

## 🎨 不同设计需求的工作流

### Logo设计工作流

```
步骤1：需求梳理
- 品牌名
- 行业特点
- 目标受众
- 风格偏好

步骤2：AI生成
- Ideogram生成带文字版本
- MidJourney生成图形版本

步骤3：选择优化
- 选出满意的方案
- 调整颜色/细节
- 生成矢量格式（用转换工具）

步骤4：测试应用
- 放在不同场景看效果
- 缩小看是否清晰
- 黑白版本是否可用
```

---

### 海报设计工作流

```
步骤1：确定内容
- 主标题
- 副标题
- 必要信息
- 风格要求

步骤2：AI生成
提示词：
A poster for [活动名],
"[标题]" as main text,
[风格描述],
[颜色偏好],
professional poster design --ar 2:3

步骤3：后期处理
- 用PS调整文字
- 添加具体信息
- 调整颜色
- 导出高清版
```

---

### 产品图工作流

```
步骤1：明确场景
- 使用场景
- 目标用户
- 氛围要求

步骤2：AI生成场景
提示词：
[产品描述] in [场景],
[氛围],
product photography style,
professional lighting

步骤3：合成产品
- 用PS把产品合成到场景
- 调整光影
- 添加阴影

步骤4：优化导出
- 调色
- 导出不同尺寸
```

## ⚠️ 注意事项

### 1. 版权问题

```
AI生成的图片：
- 可以商用（看平台条款）
- 没有版权（不能注册版权）
- 可能与他人相似

建议：
- 生成后做二次创作
- 添加原创元素
- 用于商用前看条款
```

---

### 2. 人物肖像

```
生成人物图片：
- 可能与真人相似（注意肖像权）
- 不要用于虚假宣传
- 某些用途需要标注"AI生成"
```

---

### 3. 品牌元素

```
AI生成可能包含：
- 现有品牌Logo
- 商标
- 受版权保护的角色

注意规避！
```
