## 🎯 AI视频制作全流程

### 第1步：脚本创作

**用AI写视频脚本**

**示例：**
```
你：帮我写一个30秒的短视频脚本
主题：介绍一款保温杯
风格：幽默、生活化

AI：
【脚本】保温杯的30秒自我介绍

[0-5秒]
镜头：保温杯特写
配音："大家好，我是一个保温杯"
字幕：保温杯的自我介绍

[5-15秒]
镜头：倒水画面
配音："我的主人说他爱我，但我发现..."
画面：主人又买了另一个保温杯
字幕：渣男！

[15-25秒]
镜头：保温效果展示
配音："但我还是很优秀的，
早上倒的热水，晚上还能烫嘴"
字幕：真·保温

[25-30秒]
镜头：产品特写
配音："保温杯，让渣男也离不开我"
字幕：XX保温杯
```

## 🎬 不同类型视频的制作方法

### 1. 短视频（抖音/快手/视频号）

**特点：**
- 15-60秒
- 节奏快
- 开头吸引人

**AI制作流程：**
```
1. AI写脚本（1分钟）
2. AI生成素材或找现成素材（10分钟）
3. 剪映剪辑+AI配音（15分钟）
4. 发布
```

**示例主题：**
- 产品介绍
- 知识科普
- 生活记录
- 搞笑段子

---

### 2. 中长视频（B站/YouTube）

## ⚠️ 注意事项

### 1. 版权问题

```
使用AI生成的视频：
- 可以商用（看平台条款）
- 注意肖像权（不要用真人脸）
- 注意品牌元素（不要出现商标）
```

---

### 2. 质量控制

```
AI生成的视频：
- 可能不连贯
- 可能有瑕疵
- 需要人工筛选

不要完全依赖AI
```

---

### 3. 真实性

```
AI视频制作：
- 要标注"AI生成"（某些平台要求）
- 不要制作虚假信息
- 不要用于欺诈
```
