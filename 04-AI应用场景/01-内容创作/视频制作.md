## 💡 实战案例

### 案例1：短视频制作流程

**需求：** 制作一条 AI 工具推荐短视频

**流程：**

**第1步：写文案**
```
用 ChatGPT 生成文案：

"5个免费AI工具，让你的效率直接起飞！

1. ChatGPT - 对话神器
2. DeepSeek - 国产之光
3. Pika - 视频生成
4. Suno - 音乐创作
5. Canva - 设计必备

赶紧收藏试试！"
```

**第2步：生成配音**
```
用 ElevenLabs 生成配音：
- 选择声音：Rachel（专业女声）
- 调整参数：Stability 70, Clarity 80
- 生成音频文件
```

**第3步：生成视频**
```
用 Pika 生成视频：
- 为每个工具生成 3 秒视频
- Prompt: "AI tool interface showing [tool name], futuristic, tech style"
```

**第4步：剪辑合成**
```
用剪映剪辑：
- 导入所有素材
- 添加字幕
- 添加背景音乐
- 调整节奏
- 导出视频
```

**总耗时：** 30-60 分钟

### 案例2：产品展示视频

**需求：** 为产品制作展示视频

**流程：**

**第1步：准备产品图片**
```
拍摄或用 AI 生成产品图片
```

**第2步：图片生成视频**
```
用 Runway Gen-2：
1. 上传产品图片
2. 选择运动方式：旋转
3. 生成 4 秒视频
```

**第3步：添加配音**
```
用 ElevenLabs：
"这是我们最新推出的 AI 笔记应用，支持智能总结、语音转文字等功能..."
```

**第4步：后期处理**
```
用剪映：
- 添加产品卖点字幕
- 添加背景音乐
- 添加品牌 Logo
```

## 🎯 AI 视频制作最佳实践

### ✅ DO（推荐做法）

1. **脚本优先**
   ```
   ✅ 先写好完整脚本
   ✅ 再生成视频素材
   ```

2. **批量生成**
   ```
   ✅ 一次生成多个版本
   ✅ 选择最好的使用
   ```

3. **保持一致性**
   ```
   ✅ 使用统一的配音风格
   ✅ 保持视频风格一致
   ```

4. **添加人工润色**
   ```
   ✅ AI 生成 + 人工调整
   ✅ 加入个人风格
   ```

---

### ❌ DON'T（避免做法）

1. **完全依赖 AI**
   ```
   ❌ AI 生成后直接发布
   ```

2. **忽略版权**
   ```
   ❌ 使用未授权的素材
   ```

3. **过度生成**
   ```
   ❌ 生成太多相似视频
   ```
