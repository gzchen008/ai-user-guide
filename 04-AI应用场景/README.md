## 💡 实战案例

### 案例一：用AI写公众号文章
```
场景：每周需要写3篇公众号文章
工具：Claude + ChatGPT
流程：
1. 用ChatGPT头脑风暴选题
2. 用Claude写初稿
3. 用AI润色和排版
4. 用MidJourney配图

效果：时间从4小时/篇 → 1小时/篇
```

### 案例二：用AI做视频
```
场景：做抖音短视频
工具：ChatGPT + 可灵 + 剪映
流程：
1. 用ChatGPT写脚本
2. 用可灵生成视频素材
3. 用剪映剪辑和配音

效果：从零开始3天做出10条视频
```

### 案例三：用AI学习编程
```
场景：零基础学Python
工具：ChatGPT + Claude
方法：
1. 让AI制定学习计划
2. 不懂的直接问AI
3. 让AI出题练习
4. 让AIreview代码

效果：3个月找到工作
```

## 🗓️ AI 应用场景每周计划

如果你想系统性地尝试各种 AI 应用场景，可以参考以下周计划：

| 天数 | 场景 | 具体任务 | 推荐工具 |

| 周一 | 文档处理 | 用 AI 写一篇工作邮件 | ChatGPT / DeepSeek |

| 周三 | 图片设计 | 用 AI 生成一张海报 | Ideogram / MidJourney |
