## 🎯 AI自媒体应用

### 1. 选题策划

**让AI帮你找选题**

**示例：**
```
你：我是做职场干货的小红书账号，
请给我10个爆款选题

AI：
📝 职场类爆款选题

1. 《入职第一天，我犯的3个致命错误》
2. 《同事都在用的Excel技巧，建议收藏》
3. 《领导为什么不喜欢你？5个原因》
4. 《面试时这样说，HR直接录用你》
5. 《职场新人必知的20个潜规则》
6. 《我是如何3年升2级的》
7. 《年终总结这样写，领导眼前一亮》
8. 《同事借钱不还？这样处理》
9. 《996还是955？过来人告诉你》
10. 《35岁危机？这3个准备要做好》

💡 爆款特点：
- 痛点明确
- 标题吸引人
- 有实用价值
```

### 2. 内容创作

**AI辅助内容生产**

#### 小红书笔记

```
你：请写一篇小红书笔记
主题：职场新人如何快速适应
风格：亲切、有共鸣
要求：emoji、段落清晰

AI：
【小红书笔记】

姐妹们谁懂啊😭
入职3个月，我终于活下来了！

作为一个职场小白，
今天分享我的血泪经验👇

✅ 关于穿着
第一天穿得太正式，像个卖保险的...
后来发现，观察同事怎么穿就行
建议：先保守，后调整

✅ 关于提问
不懂就问？错！
要先自己思考，再提问
领导喜欢"带着答案来提问"的人

✅ 关于社交
不要第一天就想交朋友
先做好自己的事
真诚最重要

✅ 关于加班
新人不要主动996
但也别一到点就跑
看团队文化，融入很重要

💡 3个月心得：
职场不是学校
没有人有义务教你
但只要你用心，机会会来的

#职场新人 #职场干货 #打工人日常
```

## 💡 AI自媒体技巧

### 技巧1：保持个人特色

```
❌ 不要：
完全用AI生成，没有个人风格

✅ 应该：
- AI生成初稿
- 加入个人观点
- 融入真实案例
- 保持你的声音

读者要的是"你"，不是AI
```

---

### 技巧2：批量生产

```
一天做一周的内容：

上午（2小时）：
1. AI生成10个选题
2. 选定7个
3. AI生成7篇初稿

下午（3小时）：
1. 修改润色
2. 制作配图
3. 排版调整
4. 定时发布

效率提升5倍！
```

---

### 技巧3：数据驱动

```
让AI帮你分析数据：

你：这是我最近10篇笔记的数据：
[数据列表]
请分析：
1. 什么类型的内容表现最好？
2. 什么时间段发布效果最好？
3. 有什么改进建议？

AI会帮你找出规律
```

---

### 技巧4：多平台分发

```
一篇内容，多平台用：

1. 写一篇公众号长文
2. 改成小红书笔记（短）
3. 提取要点发微博
4. 做成短视频发抖音

AI帮你快速改写
```

---

### 技巧5：互动自动化

```
用AI辅助互动：

- AI生成评论回复
- AI回复常见问题
- AI生成互动话题

但重要评论还是要亲自回
```

## ⚠️ 注意事项

### 1. 平台规则

```
注意各平台规则：

- 原创要求
- 转载标注
- 商业内容标注
- AI内容标注（某些平台要求）

违反规则可能被限流或封号
```

---

### 2. 内容质量

```
AI内容可能的问题：

- 太套路化
- 缺少真实感
- 可能有错误

务必：
- 人工审核
- 加入真实元素
- 保持质量
```

---

### 3. 版权问题

```
AI生成的内容：

- 图片可能有版权问题
- 文字可能和别人相似
- 商用要注意授权

建议做二次创作
```

---

### 4. 不要过度依赖

```
AI是工具，不是替代品：

- 你的观点最重要
- 你的经历最真实
- 你的风格最独特

AI帮你提效，但不能替代你
```
