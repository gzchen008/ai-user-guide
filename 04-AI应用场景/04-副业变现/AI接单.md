
   ```
   ✅ 关注 AI 工具更新
   ✅ 学习新的应用场景
   ```

---

### ❌ DON'T（避免做法）

1. **过度承诺**
   ```
   ❌ 承诺做不到的效果
   ```

2. **价格战**
   ```
   ❌ 用低价竞争
   ❌ 降低服务质量
   ```

3. **忽视版权**
   ```
   ❌ 使用未授权素材
   ❌ 侵犯他人版权
   ```

4. **完全依赖 AI**
   ```
   ❌ AI 生成后直接交付
   ❌ 不做人工审核和优化
   ```
