## 💡 AI PPT制作技巧

### 技巧1：明确需求

```
告诉AI：
- 主题是什么
- 目标受众是谁
- PPT时长
- 重点内容

示例：
"请帮我做一个15分钟的工作汇报PPT，
汇报对象是公司高管，
主要内容包括：Q1业绩、项目进展、Q2计划"
```

---

### 技巧2：结构化内容

```
好的PPT结构：
1. 封面
2. 目录
3. 背景/问题
4. 解决方案
5. 详细内容
6. 总结
7. 问答
```

---

### 技巧3：精简文字

```
❌ 不要：
在PPT上放大量文字

✅ 应该：
- 每页3-5个要点
- 每个要点一行字
- 用图表代替文字
```

---

### 技巧4：视觉设计

```
设计原则：
- 统一配色（2-3种颜色）
- 统一字体（2种以内）
- 适当留白
- 图文结合
```

---

### 技巧5：AI写演讲稿

```
你：请为第5页"解决方案"写演讲稿

AI：
"接下来，让我为大家介绍我们的解决方案。
首先，我们采用了最新的AI技术...
[详细演讲内容]
```

## ⚠️ 注意事项

### 1. 数据核实

```
AI可能生成：
- 错误的数据
- 虚假的案例
- 过时的信息

务必核实重要数据！
```

---

### 2. 设计调整

```
AI生成的设计：
- 可能不符合公司风格
- 需要调整配色
- 需要加入公司Logo

记得二次调整！
```

---

### 3. 内容精简

```
AI容易生成过多内容：
- 删除不必要的页面
- 精简文字
- 突出重点
```

## 🎨 PPT设计建议

### 配色方案

```
商务风格：
- 深蓝 + 白 + 灰
- 黑 + 白 + 金

科技风格：
- 蓝 + 紫 + 渐变
- 黑 + 蓝绿

清新风格：
- 白 + 绿 + 浅蓝
- 米色 + 粉 + 灰
```

---

### 字体选择

```
中文：
- 标题：思源黑体、微软雅黑
- 正文：微软雅黑、苹方

英文：
- 标题：Arial、Helvetica
- 正文：Calibri、Open Sans
```

---

### 图表使用

```
什么时候用什么图表：

趋势变化 → 折线图
比例占比 → 饼图
对比数据 → 柱状图
流程步骤 → 流程图
关系结构 → 组织架构图
```
