## 🔥 核心功能

### 1. 对话聊天

**最基础的功能，但也是最强大的。**

**使用场景：**
- 日常问答
- 知识查询
- 创意讨论
- 头脑风暴

**示例：**
```
你：请解释一下"量子纠缠"，用简单的话

AI：量子纠缠就像"心灵感应"。
想象两枚硬币，无论相隔多远，
一枚正面朝上，另一枚就必定反面朝上。
这种"超距作用"让爱因斯坦都觉得很神奇。
```

---

### 2. 写作助手

**ChatGPT最强的能力之一。**

**能写什么：**
- ✅ 文章（公众号、博客、新闻）
- ✅ 邮件（工作邮件、私人邮件）
- ✅ 文案（广告、营销、产品介绍）
- ✅ 报告（工作汇报、分析报告）
- ✅ 小说（短篇、故事）
- ✅ 诗歌（现代诗、古诗）

**示例：**
```
你：帮我写一封请假邮件，原因是去医院看病

AI：
主题：请假申请

尊敬的领导：

您好！

因身体不适，需前往医院就医，特向您申请明天（X月X日）请假一天。
工作已提前安排妥当，如有紧急事务，我会及时响应。

望批准，谢谢！

此致
敬礼

[你的名字]
[日期]
```

---

### 3. 翻译

**支持100+语言，翻译准确度极高。**

**特点：**
- 支持语境翻译（不是逐字翻译）
- 可以指定翻译风格
- 可以保留专业术语

**示例：**
```
你：把这段翻译成正式的商务英文：
"我们公司成立于2020年，主要做AI软件开发。"

AI：
"Founded in 2020, our company specializes in AI software development."
```

### 4. 代码编写

**ChatGPT是程序员的神器。**

**能做什么：**
- ✅ 写代码（各种编程语言）
- ✅ 找Bug（帮你找错误）
- ✅ 解释代码（逐行解释）
- ✅ 重构代码（优化代码）
- ✅ 写注释（添加说明）
- ✅ 写文档（使用说明）

**示例：**
```
你：用Python写一个计算器

AI：
```python
def calculator():
    """简单的计算器"""
    print("选择操作：")
    print("1. 加法")
    print("2. 减法")
    print("3. 乘法")
    print("4. 除法")

    choice = input("请选择(1/2/3/4): ")
    num1 = float(input("第一个数字: "))
    num2 = float(input("第二个数字: "))

    if choice == '1':
        print(f"{num1} + {num2} = {num1 + num2}")
    elif choice == '2':
        print(f"{num1} - {num2} = {num1 - num2}")
    elif choice == '3':
        print(f"{num1} × {num2} = {num1 * num2}")
    elif choice == '4':
        print(f"{num1} ÷ {num2} = {num1 / num2}")

calculator()
```
```

## 💡 使用技巧

### 技巧1：角色扮演

```
你是一位资深营养师，请给我设计一周的健康食谱

AI会以营养师的身份回答，更专业、更实用
```

---

### 技巧2：分步骤提问

```
❌ 一次问太多：
请帮我写一份完整的市场调研报告

✅ 分步提问：
第1步：请列出市场调研报告的大纲
第2步：请写第一部分"市场概况"
第3步：请写第二部分"竞争分析"
...
```

---

### 技巧3：提供示例

```
请模仿这种风格写文案：

示例："不贵，但很珍贵。"

现在请为我们的咖啡写一句slogan
```

---

### 技巧4：追问优化

```
AI：（给出一个回答）

你：能更详细一点吗？
你：这个观点能举个具体例子吗？
你：我不太理解，能换个说法吗？
```

## ⚠️ 注意事项

### 1. 不要分享敏感信息

```
❌ 不要告诉ChatGPT：
- 密码
- 身份证号
- 银行卡号
- 公司机密

✅ 可以分享：
- 公开信息
- 学习问题
- 工作求助（不含机密）
```

---

### 2. 核实重要信息

```
AI可能会"一本正经地胡说八道"

重要信息一定要自己核实：
- 数据、事实
- 专业建议（医疗、法律）
- 实时信息
```

---

### 3. 国内访问困难

```
ChatGPT在国内访问困难，需要：
- 科学上网
- 国外手机号/邮箱

建议：优先使用DeepSeek（国产、免费、强）
```
