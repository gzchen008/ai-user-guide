**🎯 使用场景：**

- 🧠 **知识查询**：快速了解任何陌生领域
- 💡 **创意讨论**：一起头脑风暴，激发创意
- 🎭 **角色扮演**：让AI扮演特定角色回答问题

1️⃣ 关闭不必要的程序

   - 开机启动项管理（msconfig）

2️⃣ 清理系统
   - 磁盘清理（C盘右键-属性-清理）
   - 删除临时文件
   - 卸载不用的软件

3️⃣ 优化设置
   - 减少开机启动项
   - 关闭特效（右键此电脑-属性-高级-性能设置）

5. 🍃 制造出食物（葡萄糖）和氧气（美味佳肴+新鲜空气）

所以植物通过光合作用：
- 🍽️ 自己制造食物（生长）
- 🌬️ 给我们提供氧气（呼吸）

这就是为什么我们要保护植物啦！

    print("2. 减法")
    print("3. 乘法")

calculator()

```
你是一位资深营养师，请给我设计一周的健康食谱

AI会以营养师的身份回答，更专业、更实用
```

---

### 技巧2：分步骤提问

```
❌ 一次问太多：
请帮我写一份完整的市场调研报告

✅ 分步提问：
第1步：请列出市场调研报告的大纲
第2步：请写第一部分"市场概况"
第3步：请写第二部分"竞争分析"
...
```

---

### 技巧3：提供示例

```
请模仿这种风格写文案：

示例："不贵，但很珍贵。"

现在请为我们的咖啡写一句slogan
```

---

### 技巧4：追问优化

```
AI：（给出一个回答）

你：能更详细一点吗？
你：这个观点能举个具体例子吗？
你：我不太理解，能换个说法吗？
```
