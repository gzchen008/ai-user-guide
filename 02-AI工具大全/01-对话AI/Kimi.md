## 🔥 核心功能

### 1. 超长文本处理

**Kimi的杀手锏！**

**能处理多长？**
- 支持200万字上下文
- 相当于好几本书
- 国产AI中遥遥领先

**使用场景：**
- 📚 阅读整本书
- 📄 分析超长报告
- 📜 整理历史资料
- 📝 汇总多篇论文

**示例：**
```
你：[上传一本50万字的小说]
请总结这本书的主要内容

Kimi：这本小说主要讲述了...
[会完整阅读整本书后总结]
```

## 🔧 高级技巧

### 技巧1：多轮深度对话

```
不要一次性问太多问题，分步骤深入：

第1轮：先了解概况
"这份报告主要讲了什么？"

第2轮：深入细节
"第三章提到的数据分析方法具体是什么？"

第3轮：关联分析
"这个结论和第二章的数据有什么关系？"

第4轮：总结输出
"帮我总结整个报告的核心要点"
```

---

### 技巧2：结构化输出

```
让Kimi按特定格式输出：

"请分析这份文档，并按以下格式输出：

## 核心观点
- 观点1
- 观点2

## 数据支持
| 数据项 | 数值 | 说明 |
|--------|------|------|

## 行动建议
1. 短期：xxx
2. 中期：xxx
3. 长期：xxx"
```

---

### 技巧3：角色扮演

```
让Kimi扮演特定角色：

"你现在是一位资深产品经理，请帮我：
1. 分析这份用户调研报告
2. 提取用户痛点
3. 给出产品优化建议
4. 制定优先级排序"

这样Kimi会从专业角度回答
```
