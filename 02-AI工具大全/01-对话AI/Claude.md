## 🔥 核心功能

### 1. 超长文本处理

**Claude最强的地方！**

**能处理多长？**
- 200K token ≈ 15万个汉字
- 相当于一本书的长度

**使用场景：**
- 📖 阅读整本书
- 📄 分析长篇报告
- 💻 审查大段代码
- 📝 总结长文档

**示例：**
```
你：[上传一份200页的PDF报告]
请总结这份报告的核心观点

Claude：这份报告主要讨论了以下5个核心观点：
1. AI技术正在快速改变传统行业
2. ...
```

## 💡 使用技巧

### 技巧1：充分利用长文本

```
❌ 不要：
"我有一本书要总结，我一句句发给你"

✅ 应该：
直接上传整本书的PDF
让Claude一次性处理
```

---

### 技巧2：指定写作风格

```
你是一位资深记者，请用新闻报道的风格，
写一篇关于AI发展的文章
```

---

### 技巧3：多轮优化

```
第1轮：请写一篇关于环保的文章
第2轮：语言要更生动一些
第3轮：加入一些具体案例
第4轮：开头要更吸引人
```

---

### 技巧4：使用Artifacts

```
请创建一个[产品]：
- 会显示右侧预览
- 你可以直接看到效果
- 不满意可以立即调整
```

## ⚠️ 注意事项

### 1. 不支持联网

```
Claude不能搜索实时信息

❌ 不适合：
- 最新新闻
- 实时数据
- 时效性强的内容

✅ 适合：
- 知识问答
- 写作创作
- 长文本分析
```

---

### 2. 不支持图片生成

```
Claude可以：
✅ 理解你上传的图片
✅ 分析图片内容

Claude不能：
❌ 生成图片（用MidJourney或DALL-E）
```

---

### 3. 国内访问

```
Claude官网在国内访问困难

替代方案：
- 使用Poe平台（集合多种AI）
- 使用国内镜像站
```
