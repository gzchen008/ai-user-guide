#### 案例1：算法实现
```
用户：用 Python 实现快速排序，并添加详细注释

GLM：
```python
def quick_sort(arr):
    """
    快速排序算法实现
    
    原理：
    1. 选择基准元素（pivot）
    2. 将数组分为两部分：小于pivot和大于pivot
    3. 递归排序两部分
    4. 合并结果
    
    时间复杂度：
    - 平均：O(n log n)
    - 最坏：O(n²)
    
    空间复杂度：O(log n)
    """
    # 基线条件：空数组或单元素数组已经排序
    if len(arr) <= 1:
        return arr
    
    # 选择基准元素（这里选择中间元素）
    pivot = arr[len(arr) // 2]
    
    # 分区
    left = [x for x in arr if x < pivot]      # 小于pivot
    middle = [x for x in arr if x == pivot]   # 等于pivot
    right = [x for x in arr if x > pivot]     # 大于pivot
    
    # 递归排序并合并
    return quick_sort(left) + middle + quick_sort(right)


# 测试
if __name__ == "__main__":
    test_arr = [64, 34, 25, 12, 22, 11, 90]
    print(f"原数组: {test_arr}")
    
    sorted_arr = quick_sort(test_arr)
    print(f"排序后: {sorted_arr}")
```

排序后: [11, 12, 22, 25, 34, 64, 90]

## 🔧 高级用法

### 1. API 调用

**Python 示例：**
```python
from zhipuai import ZhipuAI

client = ZhipuAI(api_key="your_api_key")

response = client.chat.completions.create(
    model="glm-5",
    messages=[
        {"role": "user", "content": "你好！"}
    ]
)

print(response.choices[0].message.content)
```

### 2. 图像理解 API

```python
from zhipuai import ZhipuAI

client = ZhipuAI(api_key="your_api_key")

response = client.chat.completions.create(
    model="glm-5",
    messages=[
        {
            "role": "user",
            "content": [
                {"type": "text", "text": "这张图片里有什么？"},
                {
                    "type": "image_url",
                    "image_url": {
                        "url": "https://example.com/image.jpg"
                    }
                }
            ]
        }
    ]
)

print(response.choices[0].message.content)
```

### 3. 流式输出

```python
from zhipuai import ZhipuAI

client = ZhipuAI(api_key="your_api_key")

response = client.chat.completions.create(
    model="glm-5",
    messages=[
        {"role": "user", "content": "讲个故事"}
    ],
    stream=True
)

for chunk in response:
    print(chunk.choices[0].delta.content, end="")
```
