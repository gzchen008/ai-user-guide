# 通义千问（Qwen）

> 阿里巴巴的 AI 大模型，国产之光的代表

---

## 📖 简介

**通义千问**是阿里巴巴推出的大语言模型，代号 Qwen（通义千问的英文缩写），是国产 AI 的重要代表之一。

**开发商：** 阿里云
**发布时间：** 2023年4月
**最新版本：** Qwen2.5-Max
**定位：** 全能型 AI 助手

---

## ✨ 核心特点

### 1. 强大的中文能力
- 中文理解和生成能力强
- 支持文言文、古诗词
- 懂中国文化背景

### 2. 多模态能力
- **文本对话**：问答、写作、编程
- **图像理解**：看图说话、图表分析
- **文档处理**：PDF、Word、Excel
- **视频理解**：视频内容分析（部分版本）

### 3. 超长上下文
- 支持 128K 上下文（约 10 万字）
- 处理长文档无压力
- 适合论文分析、合同审查

### 4. 免费使用
- 网页版完全免费
- API 调用有免费额度
- 阿里云用户有更多优惠

## 🛠️ 使用方法

### 方法1：网页版（推荐）

1. **访问官网**
   - 网址：https://tongyi.aliyun.com
   - 点击"立即体验"

2. **登录账号**
   - 支持支付宝、淘宝账号
   - 或手机号注册

3. **开始对话**
   - 直接输入问题
   - 支持上传文件

---

### 方法2：手机 App

1. 应用商店搜索"通义千问"
2. 下载并安装
3. 登录后即可使用

**App 特色功能：**
- 语音对话
- 拍照识题
- 文档扫描

---

### 方法3：API 调用（开发者）

```python
# 安装 SDK
pip install dashscope

# 调用 API
import dashscope
from dashscope import Generation

dashscope.api_key = "YOUR_API_KEY"

response = Generation.call(
    model='qwen-max',
    prompt='你好，请介绍一下自己'
)
print(response.output.text)
```

**API 定价：**
- 有免费额度
- 按调用次数计费
- 阿里云用户有优惠

## 💡 使用技巧

### 技巧1：利用超长上下文

```
场景：分析一份 50 页的 PDF 报告

❌ 不好的做法：
分段发送，每次问一部分

✅ 好的做法：
直接上传整个 PDF，让通义千问一次性分析
```

---

### 技巧2：善用文档处理

```
你：帮我分析这份合同，指出潜在风险

[上传合同 PDF]

通义千问：
这份合同有以下风险点：
1. 第3条：付款条款不明确...
2. 第7条：违约责任过轻...
3. 第12条：保密条款缺失...
```

---

### 技巧3：多模态应用

```
你：[上传一张数据图表]
帮我分析这个销售数据的趋势

通义千问：
根据图表分析：
1. 总体趋势：上升
2. 峰值出现在 8 月
3. 建议：加强 Q3 营销投入
```

## ⚠️ 注意事项

   - 敏感信息不要上传
