## 🎯 核心功能

### 1. AI 对话 (Chat)

**用途：** 问 AI 任何编程问题

```
快捷键：Cmd+L / Ctrl+L

你可以问：
- "这段代码是什么意思？"
- "怎么实现用户登录功能？"
- "帮我找出这个 bug"
- "优化这段代码的性能"
```

**实战例子：**
```
你：帮我写一个函数，检查邮箱格式是否正确

AI：
function isValidEmail(email) {
  const emailRegex = /^[^\s@]+@[^\s@]+\.[^\s@]+$/;
  return emailRegex.test(email);
}

// 使用示例
console.log(isValidEmail("test@example.com")); // true
console.log(isValidEmail("invalid-email")); // false
```

---

### 2. 内联编辑 (Inline Edit)

**用途：** 直接在代码中让 AI 修改

```
快捷键：Cmd+K / Ctrl+K

选中代码 → 按 Cmd+K → 输入修改需求
```

**实战例子：**
```javascript
// 选中这段代码
function add(a, b) {
  return a + b;
}

// 按 Cmd+K，输入："添加参数验证，确保 a 和 b 都是数字"

// AI 修改后：
function add(a, b) {
  if (typeof a !== 'number' || typeof b !== 'number') {
    throw new Error('参数必须是数字');
  }
  return a + b;
}
```

### 3. 代码补全 (Tab)

**用途：** AI 预测你要写的代码

```
只要开始写代码，AI 会自动给出建议
按 Tab 接受建议
```

**实战例子：**
```javascript
// 你输入：
function calculate

// AI 自动补全：
function calculateTotal(items) {
  return items.reduce((sum, item) => sum + item.price * item.quantity, 0);
}
```

## 🎓 使用技巧

### 1. 写好提示词

```
❌ 不好的提示：
"帮我写个函数"

✅ 好的提示：
"帮我写一个 JavaScript 函数：
- 功能：验证手机号格式
- 支持：中国大陆 11 位手机号
- 返回：布尔值
- 添加详细注释"
```

### 2. 利用上下文

```
在对话框中：
- @文件名 - 引用特定文件
- @Codebase - 引用整个代码库
- @Docs - 引用项目文档
- @Web - 搜索网络信息
```

### 3. 分步骤开发

```
不要一次性让 AI 生成整个项目：

第 1 步："帮我创建项目基础结构"
第 2 步："添加用户登录功能"
第 3 步："实现数据展示页面"
第 4 步："添加样式美化"
第 5 步："优化性能"
```

### 4. 善用审查

```
AI 生成代码后：
1. 不要直接接受
2. 让 AI 解释代码逻辑
3. 问有没有潜在问题
4. 让 AI 提供测试用例
```
