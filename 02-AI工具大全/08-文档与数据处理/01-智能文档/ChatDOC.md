## 💡 高级技巧

### 技巧1：精准提问

```
❌ 不好的问题：
"这个怎么样？"
"相关信息"

✅ 好的问题：
"第5章的主要观点是什么？"
"项目预算的分配情况如何？"
"报告中提到的3个风险因素有哪些？"
```

### 技巧2：多轮提问

```
第1轮："项目的主要目标是什么？"
第2轮："这些目标如何衡量？"
第3轮："目前的完成进度如何？"
第4轮："还存在哪些挑战？"

逐步深入，获得完整信息
```

### 技巧3：格式化提问

```
格式："请按照[格式]回答[问题]"

示例：
"请按照表格格式列出项目的所有里程碑"
"请按照时间顺序排列这些事件"
"请按照重要性排序这些因素"
```

### 技巧4：批处理

```
同时提问多个相关问题：
"1. 项目的总体预算是多少？
2. 预算主要分配在哪些方面？
3. 各部分的占比如何？
4. 有无超支风险？"
```

## 🔧 最佳实践

### 文档准备

**优化建议：**
1. **格式统一**：使用清晰的标题和编号
2. **结构清晰**：层次分明，逻辑清楚
3. **内容完整**：避免缺失重要信息
4. **文字清晰**：扫描件要确保可读性

**示例格式：**
```
# 标题1
## 标题2
### 标题3
1. 要点1
2. 要点2
- 子要点A
- 子要点B
```

---

### 提问策略

**通用模板：**
```
[上下文] + [具体问题] + [期望格式]

示例：
"在项目计划书第3章中，请详细说明时间安排，
请按照表格格式列出，包含开始时间、结束时间和负责人。"
```

**高频问题类型：**
1. **概括性问题**："主要内容是什么？"
2. **细节性问题**："具体数据是多少？"
3. **分析性问题**："原因和影响是什么？"
4. **总结性问题**："关键结论有哪些？"

## ⚠️ 注意事项

**潜在问题：**
- AI可能理解错误
- 复杂文档可能遗漏信息
- 专业术语可能解释不准确

**应对措施：**
- 重要信息人工核对
- 关键数据多源验证
