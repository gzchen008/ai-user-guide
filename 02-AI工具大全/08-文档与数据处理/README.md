## 🎯 如何选择文档与数据处理工具？

### 按需求选择

**📄 处理文档：**
- 复杂文档理解 → ChatDOC、Claude
- 文档生成 → Gamma、ChatGPT
- 格式转换 → ChatGPT、Claude

**📊 分析数据：**
- 商业智能 → Tableau AI
- 数据可视化 → Tableau AI、Power BI
- 快速分析 → ChatGPT（直接上传数据文件）

**🔍 信息搜集：**
- 学术研究 → Perplexity、ChatDOC
- 竞品分析 → Claude + Perplexity
- 市场报告 → ChatGPT + Tableau

## 💡 实用技巧

### 用 ChatGPT 分析数据（零代码）
```
1. 打开 ChatGPT，点击附件按钮上传 CSV/Excel 文件
2. 提问："帮我分析这份数据，找出关键趋势"
3. 追问："用图表展示销售趋势"
4. 追问："预测下个季度的销售数据"

全程不需要写代码！
```

### 用 Claude 处理长文档
```
1. 把 PDF/文档拖拽到 Claude 对话框
2. 提问："总结这份报告的要点"
3. 追问："提取所有数据指标，整理成表格"
4. 追问："基于这份报告，写一份执行摘要"

Claude 支持超长文档，特别适合论文、报告、合同。
```
