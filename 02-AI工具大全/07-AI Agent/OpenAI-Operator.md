# OpenAI Operator 完全指南

> OpenAI 出品的 AI 网页操作 Agent

---

## 📖 简介

**Operator** 是 OpenAI 于 2025 年推出的 AI Agent 产品，能够自主操作浏览器完成网页任务，如购物下单、预订餐厅、填写表单等。

**开发商：** OpenAI
**发布时间：** 2025年1月（美国首发）
**定位：** 网页任务自动化 Agent
**底层模型：** CUA（Computer-Using Agent）

---

## ✨ 核心能力

### 1. 浏览器自主操作
- 自动打开网页、点击按钮、填写表单
- 截屏理解页面内容
- 像人类一样操作网页

### 2. 实用场景
| 场景 | 示例 |
|------|------|
| 网购 | 在超市网站下单买菜 |
| 餐饮 | 在 OpenTable 预订餐厅 |
| 旅行 | 查询航班、预订酒店 |
| 表单 | 自动填写注册表单 |
| 搜索 | 多网站信息搜集比较 |

### 3. 安全机制
- 涉及支付/敏感操作时会暂停，交给用户确认
- 不会自动输入密码
- 操作过程全程可视

---

## 🛠️ 使用方法

### 使用步骤

1. **访问** ChatGPT 界面中的 Operator 入口
2. **描述任务**，例如："帮我在 Instacart 上买牛奶和面包"
3. **Operator 开始操作**——你会看到它操控浏览器的实时画面
4. **遇到支付等敏感步骤**——自动暂停让你确认
5. **任务完成**——返回结果摘要

## 🆚 Operator vs Manus

| 维度 | OpenAI Operator | Manus |
|------|----------------|-------|
| 开发商 | OpenAI | Manus AI |
| 操作范围 | 主要网页操作 | 网页 + 文件 + 更多 |
| 底层技术 | GPT + CUA | 自研 Agent |
| 生态系统 | ChatGPT 生态集成 | 独立平台 |
| 中文支持 | 有限 | 更好 |
| 价格 | ChatGPT Pro $200/月 | $29/月起 |

**选择建议：**
- 已有 ChatGPT Pro 订阅 → 用 Operator
- 想要更全面的 Agent 能力 → 用 Manus
- 中文场景为主 → Manus 更合适

## 💡 实战案例

### 案例1：超市购物
```
任务：在超市网站买一周食材

Operator 执行过程：
1. 打开 Instacart / Walmart
2. 搜索食材列表
3. 对比价格和评价
4. 加入购物车
5. 暂停——让你确认支付

耗时：3分钟（人工需要20分钟）
```

### 案例2：餐厅预订
```
任务：预订周五晚上的意大利餐厅

Operator 执行过程：
1. 打开 OpenTable
2. 搜索附近的意大利餐厅
3. 筛选评分和可用时间
4. 填写预订信息
5. 确认预订

耗时：2分钟
```

## ⚠️ 注意事项

1. **地区限制**：目前主要支持美国网站
2. **语言限制**：英文网站操作效果最好
3. **支付安全**：涉及支付会暂停让你手动确认
4. **网络要求**：需要稳定的网络连接
