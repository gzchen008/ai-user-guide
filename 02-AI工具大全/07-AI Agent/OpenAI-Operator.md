# OpenAI Operator 完全指南

> OpenAI 出品的 AI 网页操作 Agent

---

## 📖 简介

**Operator** 是 OpenAI 于 2025 年推出的 AI Agent 产品，能够自主操作浏览器完成网页任务，如购物下单、预订餐厅、填写表单等。

**开发商：** OpenAI
**发布时间：** 2025年1月（美国首发）
**定位：** 网页任务自动化 Agent
**底层模型：** CUA（Computer-Using Agent）

**一句话理解：** 告诉它你想在网页上做什么，它帮你操作浏览器完成。

---

## ✨ 核心能力

### 1. 浏览器自主操作
- 自动打开网页、点击按钮、填写表单
- 截屏理解页面内容
- 像人类一样操作网页

### 2. 实用场景

| 场景 | 具体示例 | 节省时间 |
|------|----------|----------|
| 网购下单 | 超市网站买菜、亚马逊下单 | 20分钟→3分钟 |
| 餐饮预订 | OpenTable 预订餐厅 | 10分钟→2分钟 |
| 旅行规划 | 查航班、比价、订酒店 | 30分钟→5分钟 |
| 表单填写 | 注册账号、填写申请表 | 15分钟→2分钟 |
| 信息搜集 | 多网站对比产品/价格 | 20分钟→3分钟 |
| 日程管理 | 预约会议、安排日程 | 10分钟→2分钟 |

### 3. 安全机制
- 🔒 涉及支付/敏感操作时会暂停，交给用户确认
- 🔒 不会自动输入密码
- 🔒 操作过程全程可视，随时可中断
- 🔒 登录态信息不会存储

## 🛠️ 使用方法

### 第一步：访问入口
在 ChatGPT 界面中找到 Operator 入口（需要 Pro 订阅）

### 第二步：描述任务
用自然语言描述你想做什么：
```
好的示例：
✅ "帮我在 Instacart 上买这些：牛奶2盒、全麦面包1袋、鸡蛋1盒、香蕉1把"
✅ "帮我找旧金山评分最高的意大利餐厅，预订周五晚上7点2人桌"
✅ "帮我在 Amazon 上找一款不超过500美元的降噪耳机，按评分排序"

不好的示例：
❌ "帮我买东西"（太模糊）
❌ "帮我上网"（没有具体目标）
```

### 第三步：观察执行
- Operator 会打开浏览器开始操作
- 你能看到实时画面
- 遇到需要你确认的步骤会暂停

### 第四步：确认完成
- 检查执行结果
- 涉及支付的步骤手动确认
- 任务完成后返回结果摘要

## 💡 实战案例详解

### 案例1：一周食材采购
```
📋 任务：在超市网站买一周食材

👤 你的指令：
"帮我在 Instacart 上买这些：
- 蛋白质：鸡胸肉 500g、三文鱼 2块、鸡蛋 1盒
- 蔬菜：西兰花 2颗、菠菜 1袋、胡萝卜 1袋
- 水果：香蕉 1把、苹果 6个
- 主食：全麦面包 1袋、糙米 1袋
预算控制在 $80 以内"

🤖 Operator 执行：
1. 打开 Instacart
2. 逐个搜索商品
3. 对比价格，选择性价比高的
4. 加入购物车
5. 检查总价是否在预算内
6. 暂停 → 让你确认支付

⏱️ 耗时：3分钟（人工需要20-30分钟）
```

### 案例2：旅行规划
```
📋 任务：规划周末短途旅行

👤 你的指令：
"帮我找下周六从旧金山到洛杉矶的航班，要求：
- 上午出发，经济舱
- 价格不超过 $150
- 直飞优先"

🤖 Operator 执行：
1. 打开航班搜索网站
2. 输入出发地和目的地
3. 筛选时间和价格
4. 列出3个最佳选项
5. 等待你选择后继续预订

⏱️ 耗时：5分钟（人工需要20-40分钟）
```

### 案例3：信息搜集对比
```
📋 任务：对比三款手机

👤 你的指令：
"帮我对比 iPhone 16 Pro、Samsung S25 Ultra 和 Google Pixel 10 Pro 的：
- 价格、摄像头参数、电池容量、屏幕尺寸
- 整理成表格"

🤖 Operator 执行：
1. 打开多个手机评测网站
2. 逐一查找参数
3. 汇总整理成对比表
4. 返回结果

⏱️ 耗时：3分钟（人工需要15-20分钟）
```

## ⚠️ 注意事项

1. **地区限制**：目前主要支持美国网站
2. **语言限制**：英文网站操作效果最好
3. **支付安全**：涉及支付会暂停让你手动确认
4. **网络要求**：需要稳定的网络连接
5. **隐私考虑**：操作时会截屏，注意不要涉及敏感信息
