## 🛠️ 使用方法

### 方法1：网页版（推荐）

1. **访问官网**
   - 网址：https://manus.ai
   - 需要邀请码或排队等待

2. **注册账号**
   - 使用邮箱注册
   - 或 Google 账号登录

3. **创建任务**
   - 描述你想做什么
   - Manus 会自动规划步骤
   - 确认后开始执行

---

### 方法2：API 接入（开发者）

```python
# 安装 SDK
pip install manus-sdk

# 使用示例
from manus import Agent

agent = Agent(api_key="YOUR_API_KEY")

# 让 Manus 执行任务
result = agent.run(
    task="帮我搜集最近一周的 AI 新闻",
    tools=["browser", "search"]
)

print(result.summary)
```

## ⚠️ 安全注意事项

### 1. 账号安全
- 不要给 Manus 支付密码
- 重要账号使用二次验证
- 定期检查操作日志

### 2. 隐私保护
- 敏感数据不要让 Manus 处理
- 使用前仔细阅读隐私政策
- 了解数据存储方式

### 3. 权限控制
- 只授予必要的权限
- 定期审查授权列表
- 可疑操作立即终止
