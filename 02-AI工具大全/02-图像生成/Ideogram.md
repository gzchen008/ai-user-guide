## 🔥 核心功能

### 1. 精准文字渲染

**Ideogram的杀手锏！**

**为什么厉害？**
- MidJourney、DALL-E的文字经常乱码
- Ideogram能准确渲染任何文字
- 支持中英文等各种语言

**示例：**
```
提示词：A poster saying "你好世界" in Chinese,
minimalist design

生成结果：
- 文字清晰可读
- 不会出现乱码
- 字体美观
```

---

**为什么适合：**

**示例：**

## 💡 使用技巧

### 技巧1：明确指定文字内容

```
✅ 好的提示词：
A poster with the text "Hello World"
clearly written in bold letters

❌ 不好的提示词：
A poster with some text
```

---

### 技巧2：指定字体风格

```
提示词示例：
A logo with "BRAND" in elegant serif font,
luxury style, gold and black colors
```

---

### 技巧3：使用Magic Prompt

```
开启Magic Prompt功能：
- AI会自动优化你的提示词
- 生成效果更好
- 特别是新手推荐开启
```

---

### 技巧4：多生成几次

```
Ideogram每次生成4张图：
- 不满意就重新生成
- 选择最满意的一张
- 可以基于满意的图再优化
```

---

## ⚠️ 注意事项

### 1. 艺术性不如MidJourney

```
Ideogram的优势是文字，不是艺术：

✅ 适合：
- 带文字的设计
- Logo、海报
- 简单的配图

❌ 不适合：
- 复杂艺术创作
- 超写实人像
- 复杂场景
```

---

### 2. 中文支持有限

```
虽然支持中文，但：
- 英文效果更好
- 中文字体选择较少
- 复杂中文可能出错
```

---

### 3. 分辨率限制

```
生成图片分辨率有限：
- 免费版：较低
- 付费版：可以更高

需要超高清需要用其他工具放大
```
