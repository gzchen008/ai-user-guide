## 🔥 核心功能

### 1. 精准文字渲染

**Ideogram的杀手锏！**

**为什么厉害？**
- MidJourney、DALL-E的文字经常乱码
- Ideogram能准确渲染任何文字
- 支持中英文等各种语言

**示例：**
```
提示词：A poster saying "你好世界" in Chinese,
minimalist design

生成结果：
- 文字清晰可读
- 不会出现乱码
- 字体美观
```

## 💡 使用技巧

### 技巧1：明确指定文字内容

```
✅ 好的提示词：
A poster with the text "Hello World"
clearly written in bold letters

❌ 不好的提示词：
A poster with some text
```

---

### 技巧2：指定字体风格

```
提示词示例：
A logo with "BRAND" in elegant serif font,
luxury style, gold and black colors
```

---

### 技巧3：使用Magic Prompt

```
开启Magic Prompt功能：
- AI会自动优化你的提示词
- 生成效果更好
- 特别是新手推荐开启
```

---

### 技巧4：多生成几次

```
Ideogram每次生成4张图：
- 不满意就重新生成
- 选择最满意的一张
- 可以基于满意的图再优化
```

## ⚠️ 注意事项

### 1. 艺术性不如MidJourney

```
Ideogram的优势是文字，不是艺术：

✅ 适合：
- 带文字的设计
- Logo、海报
- 简单的配图

❌ 不适合：
- 复杂艺术创作
- 超写实人像
- 复杂场景
```

---

### 2. 中文支持有限

```
虽然支持中文，但：
- 英文效果更好
- 中文字体选择较少
- 复杂中文可能出错
```

---

### 3. 分辨率限制

```
生成图片分辨率有限：
- 免费版：较低
- 付费版：可以更高

需要超高清需要用其他工具放大
```

## 🔧 高级技巧

### 技巧1：精确控制文字

```
使用引号明确文字内容：

提示词：
"A poster with the text "限时优惠"
written in bold red Chinese characters"

比模糊描述效果好很多
```

---

### 技巧2：指定字体风格

```
不同场景用不同字体：

优雅风格：
"in elegant serif font"

现代科技：
"in modern sans-serif font"

活泼可爱：
"in playful rounded font"

高端奢华：
"in sophisticated script font"
```

---

### 技巧3：控制排版布局

```
指定文字位置和大小：

"A poster with large 'SALE' text centered,
smaller subtitle 'up to 50% off' below,
product image at bottom"

这样AI会按你说的布局生成
```

---

### 技巧4：参考风格融合

```
借鉴知名设计风格：

"A poster in Apple's minimalist style,
featuring the text 'Think Different'"

"A vintage movie poster style with
'COMING SOON' in classic Hollywood font"
```
