## 🤔 什么是 Perplexity？

**Perplexity = AI + 搜索引擎**

简单来说，Perplexity 是一个结合了 AI 和搜索引擎的工具，可以直接回答你的问题，并提供来源链接。

**核心优势：**
- 🔍 **实时搜索** - 获取最新信息，不是训练数据
- 📚 **引用来源** - 所有答案都有来源链接，可追溯
- 💬 **对话式** - 可以追问和深入探索
- ⚡ **快速准确** - 秒级给出综合答案

**一句话总结：** Perplexity 是最好的 AI 搜索工具，让你像问专家一样问搜索引擎

## 🔥 核心功能详解

### 1️⃣ AI 搜索

**与普通搜索的区别：**

| 普通搜索 | Perplexity |
|----------|------------|
| 返回链接列表 | 直接给出答案 |
| 需要自己点击阅读 | AI 帮你总结 |
| 信息分散 | 综合多个来源 |
| 无上下文 | 可以追问 |

---

### 2️⃣ 来源引用

**每个答案都带来源：**

```
答案：
MidJourney V6 是目前最受欢迎的 AI 图像生成工具之一...

来源：
[1] MidJourney 官方文档
[2] TechCrunch 评测
[3] Reddit 用户讨论
[4] AI 艺术社区报告
```

**好处：**
- ✅ 可以验证信息
- ✅ 可以深入了解
- ✅ 引用有据可查

### 3️⃣ Focus 模式

**专注搜索特定领域：**

| 模式 | 说明 |
|------|------|
| **All** | 全网搜索 |

3. 输入问题

## 💡 高级技巧

### 技巧1：精确搜索语法

```
使用搜索运算符：

site:reddit.com AI 工具推荐
→ 只搜索 Reddit 上的内容

"exact match" 精确匹配
→ 搜索精确短语

2024..2025 时间范围
→ 限制时间范围
```

---

### 技巧2：选择合适的 Focus

```
不同场景用不同 Focus：

学术论文 → Academic
编程问题 → All（或直接问）
数学计算 → Wolfram|Alpha
视频教程 → YouTube
社区讨论 → Reddit
```

---

### 技巧3：追问技巧

```
好的追问让答案更精准：

1. 先问概括性问题
2. 根据回答追问细节
3. 要求举例说明
4. 请求对比分析

示例：
Q: 什么是向量数据库？
Q: 它与传统数据库有什么区别？
Q: 有哪些主流的向量数据库？
Q: Pinecone 和 Milvus 哪个更好？
```

---

### 技巧4：利用 Collections

```
建立知识管理体系：

1. 创建项目 Collection
2. 所有相关搜索保存到 Collection
3. 可以随时回顾
4. 可以分享给团队
```

---

### 技巧5：文件分析

```
上传文件后的提问技巧：

上传 PDF 论文后：
- 总结这篇论文的核心观点
- 这篇论文的方法论是什么？
- 与其他方法相比有什么优势？
- 有哪些可以改进的地方？
```

