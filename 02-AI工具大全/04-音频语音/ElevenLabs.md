## 🚀 快速开始

### 1️⃣ 注册账号

**步骤：**
1. 访问 [elevenlabs.io](https://elevenlabs.io)
2. 用 Google 或邮箱注册
3. 获得免费额度（每月 10,000 字符）

---

### 2️⃣ 生成第一段语音

**步骤：**
1. 登录后进入 "Speech Synthesis"
2. 选择语音：
   - **Rachel** - 专业女声（推荐）
   - **Adam** - 专业男声
   - **Antoni** - 温和男声
3. 输入文本：
   ```
   欢迎来到 AI 语音世界。我是 ElevenLabs 生成的语音，听起来很自然对吧？
   ```
4. 点击 "Generate"
5. 下载音频

---

### 3️⃣ 调整语音参数

**可调参数：**

| 参数 | 范围 | 效果 |
|------|------|------|
| **Stability** | 0-100 | 稳定性（高=更稳定，低=更自然） |
| **Clarity** | 0-100 | 清晰度（高=更清晰） |
| **Style Exaggeration** | 0-100 | 风格夸张度（高=更戏剧化） |

**推荐设置：**
- 有声书：Stability 70, Clarity 80
- 播客：Stability 50, Clarity 70
- 广告：Stability 40, Style 60

## 🎨 核心功能详解

### 1️⃣ 文本转语音（Text to Speech）

**基础用法：**
```
输入文本 → 选择语音 → 生成音频
```

**高级用法：**
```
支持 SSML 标签：
- <break time="1.0s" /> - 暂停1秒
- <emphasis>强调</emphasis> - 强调
- <say-as interpret-as="telephone">123456</say-as> - 电话号码读法
```

---

### 2️⃣ 声音克隆（Voice Cloning）

**功能：** 上传音频样本，AI 学习并克隆声音

**步骤：**
1. 点击 "Voice Cloning"
2. 上传 1-5 分钟的音频（清晰、无背景音）
3. 等待几分钟处理
4. 获得克隆的声音

**应用：**
- 有声书旁白
- 播客
- 视频配音
- 虚拟角色

**⚠️ 注意：** 
- 只能克隆自己的声音或获得授权的声音
- 不能用于欺诈或误导

---

### 3️⃣ 实时对话（Real-time Conversation）

**功能：** 实时生成语音，适合对话场景

**应用：**
- AI 客服
- 游戏角色
- 虚拟助手

**API 使用：**
```python
import elevenlabs

# 实时流式生成
audio_stream = elevenlabs.generate(
    text="你好，有什么可以帮你的吗？",
    voice="Rachel",
    stream=True
)

for chunk in audio_stream:
    # 实时播放
    play(chunk)
```

---

### 4️⃣ 长文本处理（Long-form Synthesis）

**功能：** 处理长文本（如有声书）

**步骤：**
1. 上传文本文件（支持 .txt, .pdf, .epub）
2. 选择语音
3. 系统自动分段处理
4. 下载完整音频

**支持长度：**
- 免费版：最多 5,000 字符/次
- 付费版：无限制

## 🔧 高级技巧

### 1️⃣ 情感控制

**方法：** 在文本中添加情感提示

**示例：**
```
[兴奋] 大家好！今天是个特别的日子！
[平静] 让我们慢慢来聊聊这个话题。
[悲伤] 这是一个令人难过的消息...
```

**效果：** AI 会调整语气和情感

---

### 2️⃣ 语速控制

**方法：** 调整标点和空格

**示例：**
```
正常语速：这是一个正常的句子。

快速：这是一个快速句子。

慢速：这... 是... 一个... 慢速... 句子。
```

---

### 3️⃣ 停顿控制

**方法：** 使用逗号、句号、换行

**示例：**
```
短停顿：这是第一句，这是第二句。

长停顿：这是第一句。

这是第二句。

自定义停顿：<break time="2.0s" />
```

---

### 4️⃣ 声音混合

**方法：** 混合多个声音特征

**步骤：**
1. 进入 "Voice Design"
2. 选择多个声音样本
3. 调整混合比例
4. 生成新声音
