## 💡 使用技巧

### 1️⃣ 提示词技巧

**基础公式：**
```
风格 + 主题 + 乐器 + 情绪 + 人声
```

**示例：**

**流行音乐：**
```
一首现代流行歌曲，欢快的节奏，
关于追逐梦想，电子琴和鼓点，
女声，充满活力
```

**摇滚：**
```
硬摇滚，重金属吉他，男声嘶吼，
叛逆主题，激烈鼓点
```

**古典：**
```
古典钢琴曲，悲伤的小调，
肖邦风格，独奏钢琴，慢板
```

**电子：**
```
电子舞曲，EDM 风格，
强劲节拍，合成器音效，
适合派对
```

**民谣：**
```
吉他民谣，温暖男声，
歌词关于家乡，简单编曲，
怀旧情感
```
