## 🔥 核心功能

### 1. 文字生成视频

**用文字描述生成视频！**

**怎么用：**
```
输入提示词：
"一只可爱的小猫在草地上追逐蝴蝶"

可灵会生成：
- 5秒左右的视频
- 小猫奔跑的画面
- 蝴蝶飞舞的效果
```

---

### 2. 图片生成视频

**让静态图片动起来！**

**使用场景：**
- 让照片变成视频
- 让画作动起来
- 让产品图旋转展示

**示例：**
```
上传：一张风景照片

可灵会：
- 添加云的飘动
- 添加水的流动
- 添加树叶的摇摆
```

---

## 💡 使用技巧

### 技巧1：写好提示词

```
✅ 好的提示词：
一只橘猫在夕阳下的海边漫步，
海浪轻轻拍打沙滩，
镜头缓慢推进，
电影级画质

❌ 不好的提示词：
猫走路
```

---

### 技巧2：描述镜头运动

```
提示词中加入：
- 镜头缓慢推进
- 镜头从左向右移动
- 俯视镜头
- 特写镜头

会让视频更有电影感
```

---

### 技巧3：控制时长

```
可灵默认生成5秒视频：
- 复杂场景建议5秒
- 简单场景可以用延长功能
- 多次延长可以到30秒+
```

---

### 技巧4：利用图片生成

```
文字生成不满意时：
1. 先用MidJourney生成满意的图片
2. 用可灵把图片变成视频
3. 效果更容易控制
```
