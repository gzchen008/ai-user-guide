## 🔥 核心功能详解

### 1️⃣ 文字生成视频

**用文字描述生成视频！**

**基础用法：**
```
提示词：
一只可爱的小猫在草地上追逐蝴蝶

可灵会生成：
- 5秒左右的视频
- 小猫奔跑的画面
- 蝴蝶飞舞的效果
```

**进阶用法：**
```
详细提示词：
在阳光明媚的春天，一片绿油油的草地上，
一只毛茸茸的橘色小猫追逐着一只黄色蝴蝶，
小猫跳跃奔跑，蝴蝶在空中翩翩飞舞，

效果：
- 更自然的运动
- 更好的光影效果
- 更专业的镜头感
```

---

### 2️⃣ 图片生成视频

**让静态图片动起来！**

**支持的图片类型：**
- 📷 照片
- 🎨 绘画/插画
- 🖼️ AI 生成的图片
- 📦 产品图

**使用方法：**
1. 点击"图生视频"
2. 上传图片（支持 JPG/PNG）
3. 输入运动描述（可选）
4. 生成视频

**示例：**
```
上传：一张风景照片
描述：云朵飘动，水面波光粼粼

可灵会：
- 添加云的飘动效果
- 添加水的流动效果
- 添加树叶的摇摆
- 自然的光影变化
```

---

### 3️⃣ 视频延长

**把视频变长！**

**操作步骤：**
```
1. 生成一个 5 秒视频
2. 选择"延长"
3. 系统会基于最后 1 秒继续生成
4. 再生成 5 秒
5. 拼接成 10 秒视频
```

**注意事项：**
- 每次延长约 5 秒
- 最长可达 30-60 秒
- 延长部分可能与原视频略有差异
- 建议场景简单的视频延长效果好

## 💡 高级使用技巧

### 技巧1：写好提示词

**提示词公式：**
```
[主体] + [场景] + [动作] + [镜头] + [风格] + [画质]
```

**示例对比：**
```
❌ 不好的提示词：
猫走路

✅ 好的提示词：
一只毛茸茸的橘猫（主体）
在夕阳下的海边沙滩上（场景）
悠闲地漫步，偶尔停下来嗅嗅海风（动作）
镜头从侧面缓慢跟拍，景深效果（镜头）
电影感，温暖色调（风格）
4K画质，高细节（画质）
```

---

### 技巧2：描述镜头运动

**常用镜头描述：**

| 镜头类型 | 提示词 | 效果 |
|----------|--------|------|
| 推进 | 镜头缓慢推进 | 放大主体，聚焦 |
| 拉远 | 镜头缓慢拉远 | 展示全貌 |
| 跟拍 | 镜头跟随主体移动 | 动态感强 |
| 环绕 | 镜头环绕主体旋转 | 360°展示 |
| 俯拍 | 俯视镜头，鸟瞰视角 | 宏大场景 |
| 仰拍 | 仰视镜头 | 主体显得高大 |

---

### 技巧3：控制运动幅度

**运动幅度描述：**

轻微运动：
- 微风吹过，树叶轻轻摇曳

中等运动：
- 行人走过街道

- 动物在草地上玩耍

剧烈运动：
- 快速奔跑

```

## ⚠️ 注意事项

### 1. 视频时长限制

```
单次生成：5-10 秒
延长后：最长约 3 分钟
建议：复杂场景保持 5 秒，简单场景可延长
```

---

### 2. 人物视频注意事项

```
⚠️ 人物视频挑战：
- 复杂动作可能不自然
- 表情变化可能僵硬
- 手部动作容易出问题

💡 建议：
- 选择简单动作（走路、站立）
- 避免复杂的手势
- 多生成几次选择最佳
- 优先用风景、动物、物体
```

---

⚠️ 注意：

```
