# 01 - 新手入门

> 零基础小白也能看懂的AI入门指南

---

## 🚀 5分钟快速了解

**什么是AI？**
AI（人工智能）就像一个超级聪明的助手，能帮你写文章、翻译、画图、写代码，就像和一个知识渊博的朋友聊天一样简单。

**为什么要学AI？**
- 💼 **工作效率**：原本2小时的工作，AI帮你10分钟搞定
- 🎨 **创意灵感**：想不出点子？AI给你100个建议
- 📚 **学习加速**：不懂的问AI，比搜索更快更精准
- 💰 **副业赚钱**：用AI接单、做自媒体、开发产品

**从哪里开始？**
完全小白 → 先看 [AI基础概念](./01-AI基础概念.md)
想马上用 → 直接看 [快速上手](./03-快速上手.md)

## ❓ 常见困惑

<details>
<summary><b>我不知道从哪里开始</b></summary>

**建议：** 从 [AI基础概念](./01-AI基础概念.md) 开始，只需要15分钟，了解基本概念后再决定下一步。

<details>
<summary><b>我完全不懂技术，能学会吗？</b></summary>

**回答：** 完全可以！现在的AI工具就像使用微信一样简单，不需要任何技术基础。只要会打字、会聊天，就能用AI。
</details>

<details>
<summary><b>学会AI需要多长时间？</b></summary>

**回答：** 
- **会用AI**：1-2天就能上手
- **用好AI**：1-2周掌握技巧
- **精通AI**：持续学习和实践

不需要学完所有内容，边用边学效果最好！
</details>

## 📅 一周学习计划

### 第1天：认识AI
- [ ] 阅读 [AI基础概念](./01-AI基础概念.md)
- [ ] 了解什么是大模型
- [ ] 知道AI能做什么、不能做什么

- [ ] 阅读 [快速上手](./03-快速上手.md)
- [ ] 注册 DeepSeek（免费）
- [ ] 完成第一次对话

### 第3天：探索工具
- [ ] 阅读 [主流AI工具](./02-主流AI工具.md)
- [ ] 尝试2-3个不同的AI工具
- [ ] 找到最适合自己的

### 第4-5天：提升技巧
- [ ] 阅读 [提问技巧](./04-提问技巧.md)
- [ ] 练习写提示词
- [ ] 对比优化前后的效果

### 第6-7天：实际应用
- [ ] 用AI完成一个实际任务
- [ ] 比如写一篇文章、做一份PPT
- [ ] 记录使用心得
