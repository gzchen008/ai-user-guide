# 提问技巧

> 让AI更懂你，回答更准确

---

## 🎯 为什么提问技巧很重要？

**同样的AI，不同人用效果完全不同！**

❌ **新手提问：**
```
写一篇文章
```

AI回复：可能写一篇泛泛而谈的文章，不是你想要的。

✅ **高手提问：**
```
帮我写一篇关于"职场时间管理"的文章
目标读者：刚入职的年轻人
字数：800字
风格：轻松幽默，有实操性
结构：开头引入 → 3个技巧 → 总结
```

AI回复：精准、实用、符合要求的文章。

**结论：** 你问得越好，AI回答越好！

## 📝 提问的万能公式

**高质量Prompt = 角色 + 任务 + 细节 + 格式**

### 1. 角色（Role）

告诉AI它是谁，它会用专业视角回答。

**示例：**
```
你是一位资深营养师
你是一位小学老师
你是一位软件工程师
你是一位文案策划
```

**对比：**
| 无角色 | 有角色 |
|--------|--------|
| "怎么减肥？" | "你是一位健身教练，我怎么减肥？" |
| AI给出通用建议 | AI给出专业健身建议 |

---

### 2. 任务（Task）

明确你要AI做什么。

**常用任务：**
| 任务类型 | 示例 |
|----------|------|
| 写作 | 写一篇文章/邮件/文案 |
| 翻译 | 翻译成中文/英文 |
| 总结 | 总结文章要点 |
| 解释 | 解释什么是XX |
| 代码 | 写一段Python代码 |
| 创意 | 给产品起个名字 |
| 分析 | 分析这段文字的优缺点 |
| 建议 | 给我一些XX建议 |

---

### 3. 细节（Details）

提供足够的背景信息。

**6W要素：**
- **Who** - 谁用？（目标读者）
- **What** - 做什么？（具体任务）
- **When** - 什么时候用？（时间背景）
- **Where** - 在哪用？（场景）
- **Why** - 为什么？（目的）
- **How** - 怎么做？（具体要求）

**示例：**
```
❌ 写一篇关于健康的文章

✅ 写一篇关于健康的文章
- 目标读者：30岁的上班族
- 场景：微信公众号文章
- 目的：帮助读者养成健康习惯
- 要求：3个实用建议，每个200字
```

---

### 4. 格式（Format）

明确输出格式。

**常见格式：**
| 格式 | 示例 |
|------|------|
| 列表 | 用1、2、3列出 |
| 表格 | 用表格对比 |
| 分段 | 每段不超过100字 |
| 代码 | 用代码块展示 |
| Markdown | 用Markdown格式 |

**示例：**
```
请用表格对比ChatGPT和DeepSeek的优缺点
```

## 🎯 10个实用提问模板

### 模板1：写文章

```
请帮我写一篇关于[主题]的文章
目标读者：[谁]
字数：[多少字]
风格：[正式/轻松/幽默]
结构：[开头 + 中间 + 结尾]
```

**示例：**
```
请帮我写一篇关于"如何提高睡眠质量"的文章
目标读者：经常失眠的年轻人
字数：500字
风格：轻松、有实操性
结构：开头（引起共鸣）+ 3个方法 + 总结
```

---

### 模板2：翻译

```
请把下面的[语言1]翻译成[语言2]
风格：[正式/口语/书面]
保留：[专业术语/人名/地名]
```

**示例：**
```
请把下面的英文翻译成中文
风格：书面、专业
保留：专业术语不翻译

[英文内容]
```

---

### 模板3：总结

```
请总结以下内容
要求：
1. 提炼[3-5个]要点
2. 每个[不超过20字]
3. 用[列表/表格]展示
```

**示例：**
```
请总结以下文章的要点
要求：
1. 提炼5个关键点
2. 每点不超过30字
3. 用编号列表展示

[文章内容]
```

---

### 模板4：学习

```
请用简单的语言解释[概念]
要求：
1. 适合[小学生/初中生/大学生]理解
2. 举一个生活中的例子
3. 说明它的应用场景
```

**示例：**
```
请用简单的语言解释"区块链"
要求：
1. 适合初中生理解
2. 举一个生活中的例子
3. 说明它的3个应用场景
```

---

### 模板5：代码

```
请用[编程语言]写一个[功能]
要求：
1. 实现[具体功能]
2. 添加详细注释
3. 提供使用示例
```

**示例：**
```
请用Python写一个网页爬虫
要求：
1. 爬取指定网页的标题和正文
2. 添加详细的中文注释
3. 提供一个使用示例
```

---

### 模板6：创意

```
请帮我构思[主题]的创意
数量：[X个]
风格：[有趣/专业/独特]
要求：[具体要求]
```

**示例：**
```
请帮我构思一个奶茶店的名字
数量：10个
风格：年轻、有创意
要求：名字不超过4个字，容易记住
```

---

### 模板7：对比

```
请对比[A]和[B]
维度：[价格/功能/优缺点等]
格式：用表格展示
```

**示例：**
```
请对比iPhone和华为手机
维度：价格、拍照、续航、系统
格式：用表格展示，每项打分（1-5星）
```

---

### 模板8：建议

```
我遇到了[问题]
背景：[具体情况]
目标：[想要达到的效果]
请给我[X条]建议
```

**示例：**
```
我遇到了工作效率低的问题
背景：每天有很多会议，碎片化时间多
目标：想在下班前完成当天任务
请给我5条实用建议
```

---

### 模板9：优化

```
请帮我优化这段[文字/代码/方案]
目标：[更简洁/更专业/更易读]
指出：[具体的优化点]
```

**示例：**
```
请帮我优化这段文案
目标：更吸引人、更有销售力
指出：哪些地方可以改得更好

[原文案]
```

---

### 模板10：角色扮演

```
你是一位[职业/角色]
背景：[具体场景]
任务：[要做什么]
要求：[详细要求]
```

**示例：**
```
你是一位资深HR
背景：我明天要去面试一个产品经理岗位
任务：帮我准备面试
要求：
1. 列出10个可能被问到的问题
2. 每个问题给出参考答案要点
3. 提供面试技巧
```

## 💡 提问的进阶技巧

### 技巧1：思维链（Chain of Thought）

让AI一步步思考，提高逻辑性。

**示例：**
```
请一步步分析这个问题：
1. 先理解问题
2. 列出关键点
3. 分析每个点
4. 给出结论

问题：[你的问题]
```

---

### 技巧2：少样本学习（Few-shot）

给AI几个示例，让它模仿。

**示例：**
```
请模仿以下风格写一段话：

示例1："春天来了，花儿开了，小鸟在枝头唱歌。"
示例2："夏天到了，知了叫了，太阳像个大火球。"

现在请写一段关于秋天的：
```

---

### 技巧3：分阶段提问

复杂任务分成多个步骤。

**示例：**
```
第一步：请列出文章大纲
（AI给出大纲）

第二步：请根据大纲写第一部分
（AI写出第一部分）

第三步：继续写第二部分
...
```

---

### 技巧4：追问和修正

AI回答不满意？继续追问！

**示例：**
```
AI：（给出了一个回答）

你：能更详细一点吗？
你：这个观点能举个具体的例子吗？
你：我不太理解第二点，能换个说法吗？
你：有没有更简单的解决方案？
```

## ⚠️ 常见错误

### 错误1：问题太模糊

❌ **模糊：**
```
写一篇文章
```

✅ **清晰：**
```
写一篇关于"如何养成阅读习惯"的文章，500字，适合年轻人
```

---

### 错误2：一次问太多

❌ **太多：**
```
帮我写一篇文章，做一张海报，再写一个视频脚本
```

✅ **分开：**
```
第一步：先帮我写一篇文章
（完成后再继续下一个任务）
```

---

### 错误3：没有上下文

❌ **无上下文：**
```
这个问题怎么解决？
```

✅ **有上下文：**
```
我的电脑开机很慢，Windows系统，8GB内存，需要3分钟才能进入桌面，请问怎么解决？
```

---

### 错误4：期望完美

❌ **期望：**
```
AI应该给我完美的答案
```

✅ **理解：**
```
AI是助手，需要人类引导和修正
AI的回答可以作为初稿，需要你完善
重要信息要自己核实
```

## ❓ 常见问题

<details>
<summary><b>Q: 提示词多长合适？</b></summary>

**A: 简单任务1-2句，复杂任务可以长一点。**

- 简单问答：1句话足够
- 写文章：3-5句话说明要求
- 复杂任务：可以分段描述

关键是：**说清楚需求，不要啰嗦**
</details>

<details>
<summary><b>Q: AI总是答非所问怎么办？</b></summary>

**A: 可能是问题不够清晰。**

尝试：
1. 提供更多背景信息
2. 明确说"我要的是..."
3. 给一个示例让AI模仿
4. 分步提问，一步步引导
</details>

<details>
<summary><b>Q: 不同AI工具的提示词通用吗？</b></summary>

**A: 大部分通用，但效果略有差异。**

- ChatGPT、Claude、DeepSeek的提示词基本通用
- 有些工具对格式要求不同
- 可以根据具体工具微调
</details>
