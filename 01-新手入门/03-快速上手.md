1. 一台电脑或手机

3. 5-10分钟时间

## 第一步：注册账号（2分钟）

### 方法1：网页版（推荐）

1. **打开网站**
   - 访问：https://www.deepseek.com
   - 点击右上角"登录/注册"

2. **注册账号**
   - 选择"手机号注册"或"微信登录"
   - 输入手机号，获取验证码
   - 设置密码（建议：字母+数字，8位以上）

3. **完成注册**
   - 填写昵称（随意）
   - 点击"完成"

**✅ 恭喜！你已经有了AI账号！**

---

### 方法2：手机App

1. 在应用商店搜索"DeepSeek"
2. 下载并安装
3. 打开App，选择"微信登录"或"手机号登录"
4. 完成注册

## 第二步：第一次对话（3分钟）

### 打开聊天界面

1. 登录后，点击"开始对话"
2. 你会看到一个聊天窗口
3. 底部有输入框

### 试试这些对话

**示例1：自我介绍**
```
你：你好，请介绍一下你自己
```

AI会回复类似：
```
你好！我是DeepSeek，一个AI助手。我可以帮你：
- 回答问题
- 写文章
- 翻译文本
- 写代码
- 创意构思
...
```

**示例2：问问题**
```
你：什么是人工智能？
```

AI会给你一个通俗易懂的解释。

**示例3：写文章**
```
你：帮我写一个关于健康生活的短文，100字左右
```

AI会生成一篇文章给你。

## 第三步：掌握基本技巧（5分钟）

### 技巧1：说清楚你的需求

❌ **不好的提问：**
```
写一篇文章
```

✅ **好的提问：**
```
帮我写一篇关于"如何提高工作效率"的文章
要求：
1. 500字左右
2. 适合上班族阅读
3. 语言通俗易懂
4. 提供3-5个实用建议
```

**为什么？** AI不是读心术，你说的越清楚，AI回答越准确。

---

### 技巧2：提供上下文

❌ **不好的提问：**
```
这个问题怎么解决？
```

✅ **好的提问：**
```
我电脑开机很慢，需要3分钟才能进入桌面
电脑配置：Windows 11，8GB内存
请问怎么解决？
```

**为什么？** AI需要背景信息才能给出针对性建议。

---

### 技巧3：分步骤提问

**场景：** 想学做一道菜

❌ **一次问太多：**
```
教我做西红柿炒蛋，包括食材、步骤、技巧、营养
```

✅ **分步提问：**
```
第1步：西红柿炒蛋需要什么食材？
第2步：具体怎么做？
第3步：有什么技巧？
```

**为什么？** 一步步来，更清晰，也方便追问。

---

### 技巧4：让AI解释

**不懂AI的回答？** 让它解释！

```
你：什么是"大语言模型"？

AI：（给出一个复杂的专业解释）

你：能说得简单一点吗？我是个小白

AI：（用更通俗的语言解释）
```

## 🎯 实战练习

### 练习1：让AI帮你写邮件

**任务：** 写一封请假邮件

**输入：**
```
帮我写一封请假邮件
原因：明天要去医院看病
请假时间：明天一天
收件人：我的领导
语气：正式、礼貌
```

**AI会生成：**
```
主题：请假申请

尊敬的领导：

您好！

因明天需要前往医院就医，特向您申请请假一天（X月X日）。
工作已提前安排妥当，如有紧急事务，我会及时响应。

望批准，谢谢！

此致
敬礼

[你的名字]
2026年2月18日
```

---

### 练习2：让AI帮你翻译

**任务：** 翻译一段英文

**输入：**
```
请把这段英文翻译成中文：
"Artificial Intelligence is transforming the way we live and work."
```

**AI会输出：**
```
人工智能正在改变我们的生活和工作方式。
```

---

### 练习3：让AI帮你学习

**任务：** 学习一个概念

**输入：**
```
请用简单的语言解释"区块链"，举一个生活中的例子
```

**AI会输出：**
```
区块链就像一个"共享账本"。

想象一下：
- 以前：只有银行知道你的账户余额
- 区块链：所有人都能看到账本，但只有你能修改自己的账

例子：
你和朋友们记账，以前只有一个人记账（可能记错）
现在每个人手里都有一本账，大家都记录同一件事
这样就不怕记错了

特点：
1. 公开透明
2. 不可篡改
3. 去中心化
```

## 💡 新手常见错误

### 错误1：期望AI什么都懂

❌ **问题：**
```
AI：我不知道今天天气（AI没有实时信息）
```

✅ **理解：**
- AI不知道实时新闻
- AI不知道刚刚发生的事
- AI的知识有截止日期

---

### 错误2：期望AI完全准确

❌ **问题：**
```
AI给出错误的答案
```

✅ **理解：**
- AI会犯错（尤其是数学、逻辑）
- 重要信息要自己核实
- AI是助手，不是权威

---

### 错误3：一次问太多

❌ **问题：**
```
请帮我：
1. 写一篇文章
2. 做一个PPT
3. 设计一张海报
4. 写一首诗
```

✅ **做法：**
- 一个任务一个任务来
- 复杂任务分解成多个小任务

## 🎓 进阶技巧

### 技巧1：角色扮演

```
你是一位资深营养师，请给我设计一周的健康食谱
```

AI会以营养师的身份回答，更专业。

---

### 技巧2：提供示例

```
请模仿这种风格写作：
示例："春风拂面，万物复苏，又是一年好时节。"

现在请写一段关于夏天的文字：
```

AI会模仿你提供的风格。

---

### 技巧3：追问细节

```
AI：（回答了一个问题）

你：能详细解释一下第二点吗？
你：有没有具体的例子？
你：如果是新手，应该怎么做？
```

通过追问获得更详细的信息。

## ❓ 常见问题

<details>
<summary><b>Q: AI回答太长了，看不完怎么办？</b></summary>

**A: 让AI总结或分段。**

```
你：请用3句话总结上面这段话
你：请分点列出关键信息
你：请只说重点，不要展开
```
</details>

<details>
<summary><b>Q: AI回答的不对怎么办？</b></summary>

**A: 指出错误，让AI重新回答。**

```
你：这个回答不太对，我想要的是...
你：能换一种方式解释吗？
你：请重新思考一下这个问题
```
</details>

<details>
<summary><b>Q: 对话记录会保存吗？</b></summary>

**A: 大部分工具会保存。**

- DeepSeek：自动保存，可以查看历史
- ChatGPT：自动保存对话历史
- 可以手动删除对话记录
</details>
