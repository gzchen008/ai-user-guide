## 💡 实用技巧

### Prompt万能模板

```
万能公式：
角色 + 任务 + 要求 + 举例

示例：
你是一位经验丰富的市场营销专家（角色），
请帮我写一篇小红书笔记（任务），
要求：开头吸引眼球，中间有干货，结尾引导互动（要求）。
例如：像这样的风格...（举例）
```

### AI工具组合使用

```
写作流程：
1. ChatGPT/Claude → 创意构思
2. DeepSeek → 扩展成文
3. Notion AI → 优化润色

设计流程：
1. AI → 文案创意
2. MidJourney → 生成图片
3. AI → 优化说明

编程流程：
1. Claude → 架构设计
2. Cursor → 代码生成
3. AI → 测试调试
```
