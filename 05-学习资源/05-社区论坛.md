## 💡 社区使用建议

### 获取价值

```
1. 多看少说（初期）
2. 善用搜索
3. 尊重规则
4. 真诚交流
5. 乐于分享

不要只索取，也要贡献
```

---

### 避坑指南

```
1. 不要盲目相信所有信息
2. 警惕广告和营销
3. 保护个人隐私
4. 遵守社区规则
5. 礼貌交流

社区是公共空间，请文明发言
```
