## 📖 优质书籍

### 入门书籍

1. **《人工智能：一种现代的方法》**
   - 作者：Stuart Russell
   - 适合：系统学习 AI 基础

2. **《深度学习》**
   - 作者：Ian Goodfellow
   - 适合：深入了解深度学习

3. **《动手学深度学习》**
   - 作者：李沐
   - 适合：实践导向学习
