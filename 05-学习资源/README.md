## 🎯 学习路径推荐

### 零基础入门（1-2周）

**第一步：了解AI是什么**
1. 看《AI 2041》建立认知
2. 看吴恩达《AI for Everyone》课程
3. 体验ChatGPT、DeepSeek等工具

**第二步：学会使用AI工具**
1. 学习Prompt基础技巧
2. 实践：用AI写文章、翻译、编程
3. 了解不同AI工具的特点

**第三步：确定学习方向**
- 想用AI工作 → 学习Prompt工程
- 想开发AI应用 → 学习编程+AI框架
- 想深入研究 → 学习机器学习理论

### 进阶学习（1-3个月）

**方向一：AI应用者**
1. 深入学习Prompt工程
2. 掌握各类AI工具
3. 学习AI工作流设计

**方向二：AI开发者**
1. 学习Python编程
2. 学习LangChain/LlamaIndex
3. 做实际项目练手

**方向三：AI研究者**
1. 系统学习机器学习
2. 阅读经典论文
3. 复现论文代码

### 高级提升（持续学习）

1. 关注最新论文和进展
2. 参与开源项目
3. 加入AI社区交流
4. 做自己的项目

## 💡 学习建议

### ✅ 推荐做法

1. **边学边用** - 学一个知识点马上用起来
2. **做笔记** - 用Notion/Obsidian整理学习内容
3. **多交流** - 加入社区，和同行讨论
4. **做项目** - 只有动手才能真正学会
5. **持续学习** - AI发展快，保持学习习惯

### ❌ 常见误区

1. **只看不练** - 理论再多不实践没用
2. **贪多求全** - 专注一个方向深入
3. **追求完美** - 先完成再完美
4. **闭门造车** - 要和社区交流
5. **过度收藏** - 收藏≠学会，学了就要用
