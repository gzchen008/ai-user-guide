## 🤖 大模型相关

### Transformers（Hugging Face）
- ⭐ **Stars**：120k+
- 📝 **简介**：最流行的预训练模型库
- 🎯 **适合**：学习NLP、使用预训练模型
- 🔗 **链接**：huggingface/transformers

**能学到什么：**
- 如何加载和使用预训练模型
- 模型微调（Fine-tuning）流程
- Tokenizer的使用方法
- 各种NLP任务的实现

**快速开始：**
```python
from transformers import pipeline

# 使用现成的情感分析模型
classifier = pipeline("sentiment-analysis")
result = classifier("I love AI!")
print(result)  # [{'label': 'POSITIVE', 'score': 0.9998}]
```

### LangChain
- ⭐ **Stars**：80k+
- 📝 **简介**：LLM应用开发框架
- 🎯 **适合**：开发AI应用、RAG系统
- 🔗 **链接**：langchain-ai/langchain

**能学到什么：**
- 如何构建AI应用
- RAG（检索增强生成）实现
- Agent（智能体）开发
- 与各种数据源集成

**快速开始：**
```python
from langchain.llms import OpenAI
from langchain.prompts import PromptTemplate

llm = OpenAI()
template = "给{product}起一个好名字"
prompt = PromptTemplate.from_template(template)
chain = prompt | llm
print(chain.invoke({"product": "AI咖啡店"}))
```

### Ollama
- ⭐ **Stars**：50k+
- 📝 **简介**：本地运行大模型
- 🎯 **适合**：想本地使用AI的人
- 🔗 **链接**：ollama/ollama

**特点：**
- 一键安装，简单易用
- 支持多种开源模型
- 本地运行，隐私安全
- 提供API接口

**快速开始：**
```bash
# 安装Ollama
curl -fsSL https://ollama.com/install.sh | sh

# 运行模型
ollama run llama2

# 使用API
curl http://localhost:11434/api/generate -d '{
  "model": "llama2",
  "prompt": "你好"
}'
```

## 💡 如何学习开源项目

### 学习步骤
```
第1步：阅读README
      ↓ 了解项目是什么、能做什么
第2步：运行示例
      ↓ 先跑起来，看看效果
第3步：阅读核心代码
      ↓ 理解主要逻辑
第4步：修改和实验
      ↓ 改改参数，看看变化
第5步：自己实现
      ↓ 尝试自己写一个简化版
```

### 高效技巧
```
✅ 不要从头读到尾 - 先看主要功能
✅ 边看边运行 - 不要只看不练
✅ 记笔记 - 记录重要知识点
✅ 提Issue - 不懂就问
✅ 看PR - 学习别人的代码
```
